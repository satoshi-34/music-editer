# Music Editor MVP

Finale ライクな楽譜作成 Web アプリの最小構成（MVP）です。  
React + TypeScript + Vite + VexFlow を使って、**クリックで五線譜に音符を配置**し、**リアルタイムで音を再生**できます。  
MuseScore 風の **小節幅の自動割り付け** と、**クリック位置の高精度スナップ**（線に置きやすいバイアス付き）を実装しています。

---

## 🎵 主要機能

### 楽譜編集
- React + TypeScript + Vite による高速な開発体験
- ト音記号・4/4 拍子の五線譜を表示（複数段レイアウト）
- クリックで音符／休符を配置（加線域も含め 0.5 行刻みでスナップ）
- 小節幅の自動割り付け（全・二分はやや広め。細かい音符は過密回避）
- 見た目の横位置に最も近い場所へ自然に挿入（getAbsoluteX + BoundingBox）
- 全音価対応（全音符・二分音符・四分音符・八分音符・十六分音符・三十二分音符・六十四分音符）

### 🎶 音符再生機能（NEW!）
- **個別音符再生**: 音符をクリックして即座に音を確認
- **譜面全体再生**: 再生ボタンで譜面全体を順次再生
- **正確な音高再生**: 五線上の位置に応じた正確な音高
- **音価対応**: 全音符から六十四分音符まで正確な長さで再生
- **テンポ調整**: BPM設定による再生速度制御
- **音色プレビュー**: スピーカーボタンで音色確認
- **ブラウザ対応**: 自動再生ポリシーに完全対応

### データ管理
- **保存・読み込み**: LocalStorageによる譜面データの永続化
- **印刷対応**: ブラウザの印刷機能で楽譜を印刷

## 使い方

### 基本操作
1. **音価選択**: 画面上の Palette で音価（全音符・二分音符・四分音符・八分音符など）や休符を選びます
2. **音符配置**: 五線譜の置きたい位置をクリックします。線／間／五線の外（加線域）も 0.5 行刻みでスナップします
3. **拍数制限**: 小節の拍数（4/4）を超える配置は無視されます

### 🎵 音符再生
1. **個別再生**: 配置した音符をクリックして音を確認
2. **全体再生**: ツールバーの再生ボタン（▶️）で譜面全体を再生
3. **音色確認**: スピーカーボタン（🔊）で現在の音色をプレビュー
4. **テンポ調整**: BPM設定で再生速度を変更

### データ管理
1. **保存**: 「保存」ボタンで譜面をLocalStorageに保存
2. **読み込み**: 「読み込み」ボタンで保存した譜面を復元
3. **印刷**: 「印刷」ボタンでブラウザの印刷ダイアログを開く

## 実装のポイント（要点）

### 1. クリック座標と描画座標の基準を統一
- クリックはクライアント座標、VexFlow は `<svg>` 内の `<g>` ユーザー座標です。
- `getScreenCTM().inverse()` を使い、**client → `<g>` ユーザー座標**へ正確に変換。
- クリック用の透明 `<rect>` も同じ `<g>` に追加し、座標系を完全一致させています。

### 2. Y 方向スナップ（音高決定）
- `stave.getSpacingBetweenLines()` を基準に **0.5 行刻み**でスナップ。
- 線に置きやすいよう **線バイアス**（`LINE_PAD_RATIO`, `LINE_BIAS`）を適用。

### 3. X 方向の挿入位置
- 各音符の `getAbsoluteX()` と幅（BoundingBox）を使い、クリック X に最も近い隙間へ挿入。

### 4. 小節幅の自動割り付け
- 音価の「占有感」に重みを持たせて比例配分。全・二分を含む小節は下限幅を広めに確保。
- 16 分や 32 分が並んでも符頭が重なりにくいようチューニング。

### 5. 🎵 音符再生システム
- **SimpleAudioEngine**: Web Audio APIを直接使用した軽量な音声エンジン
- **音高変換**: Vexflow形式（`c/4`）からMIDI形式（`C4`）への自動変換
- **音価計算**: BPMに基づく正確な再生時間計算
- **ブラウザ対応**: 自動再生ポリシーに完全対応（ユーザーインタラクション後に初期化）

## クリック精度のチューニング

`src/components/StaffCanvas.tsx` の定数で調整できます。

```ts
// 線の中心 ± (spacing * LINE_PAD_RATIO) に入れば即スナップで線確定
const LINE_PAD_RATIO = 0.18; // 例: 0.15〜0.25

// 線候補の距離スコアに掛ける係数（1 未満で線を優遇）
const LINE_BIAS = 0.82; // 例: 0.7〜0.9
```
- 線に置きづらい → `LINE_PAD_RATIO` を上げる、または `LINE_BIAS` を下げる
- 間に置きたいのに線に吸われる → `LINE_PAD_RATIO` を下げる、または `LINE_BIAS` を上げる
