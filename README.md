# Music Editor

ブラウザで動く楽譜作成アプリです。五線をクリックして音符を置き、その場で音を鳴らし、A4 の紙面のまま印刷・PDF 保存できます。
単旋律・ピアノ大譜表・弦楽四重奏・編成譜（オーケストラ／吹奏楽など）に対応しています。

この README は**ユーザー向けの取扱説明書**です。開発環境の作り方・実装の詳細・テスト手順は [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md) にまとめています。

## 1. このアプリでできること

- **ホーム画面**: 起動するとまずホームが開きます。中央に「新しく作る（譜種カード＋ファイルを開く）」と「最近使ったファイル」が並び、一覧の先頭を押せば前回の続きをワンクリックで再開できます。設定・種類別のファイル読み込みへの入口も同じ画面にあります（ログインはありません）
- **4種類の楽譜**: 単旋律（ト音記号）／ピアノ大譜表（右手＋左手）／弦楽四重奏（Vn.I / Vn.II / Va. / Vc.）／編成譜。編成譜は弦楽合奏・室内オーケストラ・二管編成オーケストラ・大編成オーケストラ・吹奏楽・歌＋ピアノ・リコーダー＋歌のテンプレートから選び、パート名・略称・音部記号・段数（1段/2段の大譜表）・並び順を自由に編集できます
- **編集レイヤーの切り替え**: ピアノ譜では「レイヤー」ボタン（右手・声部1／右手・声部2／左手・声部1／左手・声部2）が**ツールバーの「元に戻す」の隣に常設**されています。どのタブを開いていても切り替えられます（記号を付けるときも、いま選んでいるレイヤーの音符しかクリックできないため）。`V` キーで同じ手の声部だけ切替
- **音符の入力**: クリックで配置。全音符〜64分音符・付点・休符・和音・連符（2/3/4/5/6/7連符）に対応し、ピアノ譜では声部1（上声）／声部2（下声）の2声部入力ができます（いま編集していない側の声部は、音符・ビーム・連符とも薄いグレーで表示されます。印刷・PDFでは黒に戻ります）。編集対象は**「レイヤー」ボタン（右手・声部1／右手・声部2／左手・声部1／左手・声部2）**で明示的に選びます（既定は右手・声部1。`V` キーで同じ手の声部だけ切替）。別のレイヤーの音符も、その符頭をクリックすればそのまま選べます（クリックした音符のレイヤーへ自動で切り替わり、「左手・声部1に切り替えました」のように画面へ出ます）。空いている場所のクリックは、**いま選んでいるレイヤーへの入力**です（どちらの五線の上でクリックしても、選択中の手・声部に入ります。音の高さはその手の五線を物差しに決まるので、右手の低い音は左手の五線のあたりをクリックすれば加線付きで入ります。別の手へ入力したいときはレイヤーボタンで切り替えてください。違う側の五線をクリックしたときは「右手・声部1に入れました」のような案内が出ます）
- **記号**: 臨時記号（♯/♭/♮/𝄪/𝄫）、微分音（四分音）、強弱記号、松葉（クレッシェンド／デクレッシェンド）、アーティキュレーション、タイ／スラー、リピート記号と1番/2番括弧、装飾音符（前打音・トリル等）、ペダル記号、8va/8vb、リハーサルマーク、音符に紐づかない自由注釈テキスト、そして自分で描いたカスタム記号
- **テキスト**: 歌詞・コード記号・テンポ表記・発想標語・運指番号を音符に付けられます。テンポ表記と発想標語は五線の上にイタリック体、コード記号は同じく五線の上に立体（イタリックでない字）で出ます（同じ音符に複数を付けると、上からテンポ表記・発想標語・コード記号の順に並びます）。テンポ表記の入力欄では、定番の速度標語（Grave・Largo・Lento・Adagio・Andante・Andantino・Moderato・Allegretto・Allegro・Vivace・Presto・Prestissimo）を候補から選べます（入力欄をクリックするか数文字打つと候補が出ます。候補に無い言葉もこれまでどおり自由に入力できます）。候補から選んだ速度標語は、**その小節から再生テンポにも反映されます**（例: Andante なら ♩=76 前後）。候補に無い言葉を自由入力した場合は、これまでどおり表示だけで再生テンポは変わりません
- **曲の途中での変更**: 小節単位でテンポ・拍子・調号・音部記号を変えられます。曲中への小節の挿入・削除、選択範囲の移調にも対応しています
- **再生**: 譜面全体の再生（再生中の位置は譜面上に縦帯で表示）、音符クリックでの個別再生、パートごとの音色設定、スウィング再生、音量調整。トリルは主音と上隣接音の交互連打として鳴ります（全体再生時）。**ペダル記号（Ped … ✱）を置いた区間では、その間に鳴った音が音価を過ぎても解除位置まで響き続けます**（大譜表では、左手側に置いた記号でも右手の音が伸びます）。音源は内蔵音源と SoundFont を切り替えられます
- **レイアウト**: 用紙サイズ（A4／B4／A3）を選べるほか、段あたり小節数・段数/ページ・音符の大きさ・ページ余白・段の間隔・パート間隔をスライダーで調整でき、段ごとの微調整は五線の左右端をクリックして出るパネルで行えます。よく使う設定は「初期値プリセット」として保存できます
- **保存と書き出し**: 作品単位の自動保存と復元履歴（数世代）、複数の作品の保存と切り替え（作品一覧）、印刷／PDF 書き出し、MusicXML の書き出し・読み込み（読み込みは Finale 既定の圧縮形式 .mxl と、ピアノ大譜表で連符が右手↔左手をまたぐクロススタッフ記譜にも対応。またいだ音は時間を保った休符として取り込まれ、⇵ で見た目を付け直せます）、MIDI 書き出し、合奏用のパート譜表示・印刷

## 2. 最短の起動方法

### Docker（推奨・ホストに Node.js が不要）

```bash
git clone https://github.com/satoshi-34/music-editer.git
cd music-editer
docker compose up -d
```

### ローカル（npm）

```bash
git clone https://github.com/satoshi-34/music-editer.git
cd music-editer
npm ci
npm run dev
```

どちらの場合も、起動後にブラウザで http://localhost:5173 を開きます。
初回は依存のインストール（Docker ならイメージのビルド）が走るため少し時間がかかります。
テスト・lint・ビルドの実行方法や、Docker で安全に依存を追加する手順は [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md) を参照してください。

## 3. 画面・各タブの説明

### ホーム画面

アプリを開くと最初にホーム画面が出ます。Word や Excel の起動画面と同じように、左に薄いナビ（ホーム／新規／最近は押すとその見出しへ移動、**開く／設定は押すと種類別のボタンがその場に開きます**）、右に本文が並びます。カードは画面の幅いっぱいに横へ並ぶので、広い画面ほど1行に入る枚数が増えます。本文は上から順に、

- **新しく作る**: 単旋律／ピアノ／弦楽四重奏／編成譜を、譜面の形が分かる小さな絵（サムネイル）付きのカードで並べます。選ぶとその種類の空の譜面を作ります。いま編集していた内容は保存され、作品一覧に残ります。同じ行の右端にある「**ファイルを開く**」カードからは、保存済みの譜面ファイルをそのまま開けます
- **最近使ったファイル**: ブラウザに保存されている作品を、名前と最終更新日時のカードで並べます。**先頭は前回開いていた作品**（編集していなくても先頭に来ます）、残りは更新の新しい順です。押すとその作品が開きます。起動して1クリックで続きから再開できます（読み込みは裏で終わっているので待ち時間はありません）
- **開く（左レール）**: 押すと種類別のボタン（ファイル (.score.json)／MusicXML (.mxl)／PDF (β)／以前の手動保存）が開きます。譜面画面の「ファイル」タブと同じ導線です（PDF は変換サーバーがあるとき、以前の手動保存は旧データがあるときだけ出ます）。`Escape` で閉じられます
- **設定（左レール）**: 押すと楽譜設定／レイアウト／再生・音色のボタンが開き、選ぶと譜面画面のそのタブが開きます
- フッターに**アプリのバージョン**（例: `v3.6.0`）が出ます。リリースノートと突き合わせて、最新版を見ているかを確認できます

譜面画面からホームへ戻るときは、ツールバー右上の「**🏠 ホーム**」ボタンを押します。戻る前に編集内容はこの端末のブラウザへ保存されるので、「最近使ったファイル」の先頭からそのまま再開できます。

### 譜面画面

画面はいちばん上の**ツールバー（ヘッダー）**と、その下の**譜面エリア**でできています。ツールバーは6つのタブに分かれており、タブを切り替えると使える道具が変わります。

タブ行の右端には「**❓ ヘルプ**」ボタンが常設されています。「タイを付けたい」のような**やりたいことから引ける目的別ガイド**と、この説明書と同じ内容の**操作リファレンス**を、1つの検索ボックス（例:「連符 数字」）で横断して探せます。

| タブ | 置いてあるもの |
| --- | --- |
| **音符・休符** | 音価（全音符〜64分音符）・休符・付点・連符（2/3/4/5/6/7）のトグル、**タイ・臨時記号（♯/♭/♮/𝄪/𝄫）・入力時に付ける臨時記号（♩♯ など）・微分音（四分音）・リピート記号と1番/2番括弧**、連符数字の表示/非表示、段またぎ表示（⇵。ピアノ譜のみ）、小節選択ツール（クリック／ドラッグで範囲選択。他ツール中は Shift+クリック）、元に戻す／やり直す、小節の挿入・削除 |
| **演奏記号** | 強弱記号、松葉（＜／＞）、アーティキュレーション、装飾音符（前打音・トリル等）、ペダル、8va/8vb、歌詞・コード・運指などのテキスト、途中のテンポ／拍子／調号／音部記号の変更、リハーサルマーク、自由注釈テキスト（T）、カスタム記号の作成（＋）と汎用のサイズ調整（⤢）・位置調整（✥）。※タイ・臨時記号（♯/♭/♮/𝄪/𝄫）・微分音・リピート記号は「音符・休符」タブ側にあります |
| **楽譜設定** | 曲の骨格を決める設定: 楽譜の種類・編成・拍子（4/4・2/2 は C / 𝄵 の記号表示に切り替え可）・調号・パート表示・タイトルの書体／文字サイズ／太さ（タイトル・サブタイトル・作者欄の文字。明朝/ゴシック/欧文セリフのほか、浄書向きの Web フォント（EB Garamond・Playfair Display・しっぽり明朝など）から選択。文字サイズは 70〜160%、太さは「既定（タイトルのみ太字）／標準／太字」から選べ、3つとも印刷・PDF にも同じように効きます。音符・記号の書体は変わりません） |
| **レイアウト** | 紙面の見た目に関する設定です。**ツールバーの位置**（上（横）／左（縦））、表示ウェイト（細い／普通／太い）と、3つのグループ: **用紙と余白**（**用紙サイズ**（A4／B4／A3）・余白(左右)・余白(上)・余白(下)）／**譜面の密度**（音符の大きさ・小節幅の均等さ・段の間隔・パート間隔、および**段組**＝段あたり小節数・段数/ページ）／**タイトル**（タイトル余白(上)・タイトル余白(下)）。ほかに「リセット」メニュー（段割りをリセット／レイアウトをリセット／既定として保存／初期設定に戻す）。**段組の2つは楽譜の種類ごとに別々に覚えます**（楽譜設定タブで種類を切り替えると、その種類で最後に使った値に戻ります） |
| **再生・音色** | 再生／停止、小節番号を指定した再生、再生速度（%）、作品の基準テンポ、音量、楽器の選択、音色プレビュー、音源方式（内蔵音源／SoundFont）、音色詳細（明るさ・アタック感・余韻・厚み・スウィング再生） |
| **ファイル** | 新規作成・作品一覧（切替・削除・復元履歴）、**書き出しメニュー**（ファイル .score.json／MusicXML／MIDI／PDF・印刷）、**開くボタン群**（ファイル／MusicXML (.mxl)／以前の手動保存の取り込み。Safari でも確実にファイル選択が開くよう、選択式メニューではなくボタンです）、パート譜表示、サンプル譜（開発ビルドのみ） |

タブ行の右端には「**💬 フィードバック**」ボタンが常設されています。どのタブを開いていても押せるので、困った瞬間にそのままの表示状態で報告できます（タブではなくその場で送信フローが始まるボタンなので、丸みのある枠線とアイコンでタブと見分けられるようにしてあります）。ツールバーを折り畳んでいる間は、このボタンが最下段（折り畳みトグルの左隣）へ移り、譜面だけを表示したまま押せます。狭い画面では 💬 のアイコンだけになります。

タブを切り替えると、選択中のツールもそのタブの既定値に戻ります（「音符・休符」タブへ戻ったときだけ、直前に使っていた音価が復元されます）。あわせて**譜面で選んでいた音符（青枠）の選択も解除されます**。タブの切り替え・ツールの選び直し・再生の開始のいずれでも解除されるので、選んだままにしていた音符に、あとから押した `Delete` が届いてしまうことがありません。

「画面表示のズーム」（画面上の拡大縮小。印刷結果には影響しません）は、どのタブを開いていても触れるようにツールバー最下段の左端に常設しています。ツールバーを折り畳んでいる間もこの位置に残るので、譜面だけを表示したまま拡大縮小できます。50〜300% まで調節でき、パート数の多い総譜（吹奏楽・オーケストラなど）で1つ1つの五線が小さく感じるときは、200% 以上まで上げると音符をクリックしやすくなります。縮小して表示しているときは、五線や小節線が画面上でかすれて見えなくならないよう、最低限の太さを保って描きます（印刷結果や PDF 書出には影響しません）。

「レイアウト」タブの「**リセット**」ボタンを押すと、戻せる範囲がそれぞれ違う4つの操作（段割りをリセット／レイアウトをリセット／既定として保存／初期設定に戻す）が、影響範囲の説明付きで1つのメニューにまとまって出ます。押す前にどこまで戻るのかを読んでから選べます。4つとも戻すのはレイアウト設定や初期値プリセットだけで、書いた譜面（音符・記号）が消えることはありません。

「レイアウト」タブの「**ツールバーの位置**」で、ツールバーを画面の**上（横並び・既定）**と**左（縦並び）**から選べます。左を選ぶと、タブ・パレット・各種スライダーがそのまま画面左の縦帯に移り、譜面はそのぶん右へ寄ります。楽譜ソフトのパレットを左に縦置きして使い慣れている場合や、譜面を縦に長く見たい場合に向きます。選んだ位置はリロード後も維持されます。画面の幅が狭いとき（768px 未満）は、譜面の幅を確保するために自動で上（横）に戻ります（設定そのものは「左」のまま残るので、画面を広げれば左に戻ります）。

「レイアウト」タブの「**用紙サイズ**」で、紙の大きさを **A4（既定）／B4／A3** から選べます。オーケストラの総譜のように段数が多い譜面や、B4 に印刷して使いたい場合に切り替えてください。選ぶと画面のページ・印刷・PDF書き出しのすべてがその大きさになり、紙が広がったぶん1段に入る小節数や1ページに入る段数も自動で組み直されます（切り替えたときはその旨の通知が出ます）。

用紙サイズは**作品ごとの設定**として保存されるので、保存した譜面を別の環境で開き直しても同じ大きさで開きます。用紙サイズを選ぶ前に作った譜面は、これまでどおり A4 として開きます。

ツールバー右下の「**▲ ツールバーを隠す**」を押すとヘッダー全体が細い帯に折り畳まれ、譜面を広く見渡せます。左（縦）配置のときは、同じボタンで縦帯が細い帯に縮みます。折り畳み中も「**▼ ツールバーを表示**」ボタンは必ず画面に残るので、戻せなくなることはありません。折り畳み状態はリロード後も維持され、表示だけの変更なので段組み・ページ数・印刷結果には影響しません。

譜面エリアは実際の A4 用紙と同じ大きさで表示され、画面のページ割りがそのまま印刷の1枚になります。

- **五線の左右の端（音部記号の手前／終止線の外）をクリック**すると、その段が薄い枠で選択され、段のすぐ下に「**段N ◀ N小節 ▶**」「**間隔 － Npx ＋**」のパネルが出ます。段ごとに小節数と上の段との距離を微調整でき、数値をクリックすれば直接入力もできます。Enter / Esc / 譜面の他の場所をクリックで閉じ、譜面には何も残りません（印刷にも出ません）
- 最後の段の後ろには「**＋ 小節を追加**」ボタンがあり、押すと空の小節が1つずつ増えます
- ページの残りには市販の五線紙のような**薄いグレーの空の段**が表示されます。クリックするとその段が実体化して入力できるようになります

## 4. 音符入力から保存・印刷までの基本操作

1. **スコアタイプ選択**: ツールバーで「単旋律」「ピアノ」「弦楽四重奏」「編成譜」を選択します
2. **音価選択**: 画面上の Palette で音価（全音符・二分音符・四分音符・八分音符など）や休符を選びます
3. **音符配置**: 五線譜の置きたい位置をクリックします。線／間／五線の外（加線域）も 0.5 行刻みでスナップします
4. **拍数制限**: 選択中の拍子で許される小節長を超える配置は無視されます
5. **休符の編集**: 音価（音符側）のボタンを選んでいるあいだは、**休符を1回クリックするだけ**で置き換わります。たとえば 16分音符ツールで 16分休符をクリックするとそのまま 16分音符になり、8分休符の右半分をクリックすると `16分休符 + 16分音符` に分割できます。連符（2/3/4/5/6/7連符）のトグルを ON にして休符をクリックすると、その休符が連符グループに置き換わります（休符のほうが長ければ余りは休符として後ろに残ります）。押し間違えたときは「元に戻す」（`Cmd/Ctrl+Z`）で1回で戻せます。置き換えられない休符（連符の中で音価が合わない・ツールの音符のほうが長い）では何も起きず、そのことはカーソルの形（置けるときだけ「コピー」の形、置けないときは「禁止」の形）で分かります。**休符を選びたいとき**（`0` キーで標準位置へ戻す・↑/↓ で高さを動かす）は、休符側のボタンを選んでからクリックしてください
6. **連符のコピー＆貼り付け**: 三連符などの音符を1つ選んで `Cmd/Ctrl+C` を押すと、**その連符グループ全体**がコピーされます（小節を選んでいるときは、これまでどおり小節のコピーになります）。コピーしたあとは、**貼りたい休符をクリックするだけ**で同じ連符が入ります（同じ小節でも別の小節でもかまいません。休符のほうが長ければ余りは休符として後ろに残ります）。クリックする位置は休符の記号の上でなくてかまいません。**コピー中は、その休符が占める拍の幅ぜんぶ**が貼り付け先として反応します（マウスを乗せるとカーソルが「コピー」の形に変わる範囲です）。小節の空きへ足したいときは、その小節の音符を選んで `Cmd/Ctrl+V` を押します。貼れない休符（休符が短すぎる・連符の中の休符）ではカーソルが「禁止」の形になり、クリックすると理由が画面に出ます。`Cmd/Ctrl+V` で貼れないときも同じように理由が出ます（小節に空きがないときは「この小節は拍がいっぱいで置けません」、まだ何もコピーしていないときは「貼り付けられる連符グループがありません」）。コピー中は休符クリックが「貼り付け」になるので、**普通の音符入力に戻したいときは `Escape`** を押してください
7. **連符数字の非表示**: 連符（3連符など）が続くところでは、2つ目以降の数字を消せます。パレットの「連符数字の表示/非表示」ボタン（取り消し線の付いた 3）を押してから、消したい連符の音符（または連符の中の休符）をクリックしてください。**グループ単位**で切り替わり、数字といっしょに括弧も消えます（同じ連符が続くときは最初のグループにだけ数字を書く、という浄書の書き方に合わせています）。もう一度同じ場所をクリックすると元に戻ります。連符が並ぶ小節では、音符ではなく**小節の何もない場所**をクリックすると、その小節の連符の数字をまとめて消せます（1つでも表示中があれば全部消え、全部消えていれば全部戻ります。何グループ変えたかは画面下に出ます）
8. **連符の中の音符を消す**: 連符（3連符など）の音符を選んで `Delete` を押すと、**その位置だけが連符内の休符になり**、連符の囲み・数字・残りの音符はそのまま残ります（「♪♪♪」の真ん中を消すと「♪休♪」）。グループの音符を全部消して**最後の1音**になったときにだけ、グループ全体が同じ長さの普通の休符1つにまとまります。グループごと一度に消したいときは、連符の中の**休符**を選んで `Delete` を押してください
9. **保存**: 編集は約1.5秒後に自動保存され、次回そのまま続きから開けます（手動の保存ボタンはありません。過去の状態へは「作品一覧」→各作品の「履歴」から戻れます）
10. **新規作成**: 「ファイル」タブの「新規作成」は確認後、いまの内容を保存したうえで新しい作品として空の譜面を開きます（これまでの作品は「作品一覧」に残ります）
11. **印刷・PDF**: 「レイアウト」タブの「印刷プレビュー」トグルで仕上がりを画面で確認し、「ファイル」タブの「書き出し」→「PDF / 印刷」でブラウザの印刷ダイアログを開きます。送信先で「PDFに保存」を選べばそのまま PDF になります

### データ管理

1. **新規作成**: 「新規作成」ボタンで、確認後にいまの内容を保存してから、新しい作品として空の譜面を開く。確認はアプリ内のダイアログで、`Enter` で実行・`Esc` で取りやめ（ホーム画面の「新しく作る」から譜面の種類を選んで作ることもできる。この場合は種類を選ぶ操作が確認を兼ねるため、ダイアログは出ない）
2. **作品一覧**: 「作品一覧」ボタンで、ブラウザに保存されている作品を新しい順に一覧表示
3. **保存**: 手動の保存ボタンは無く、編集は自動保存される（過去の状態へは作品一覧の「履歴」から）
4. **ファイル入出力**: 「書き出し」メニューと「開く」ボタンで .score.json ファイルとして書き出し・読み込みできる
5. **サンプル**: 「サンプル譜の種類」を選んで、説明用デモ譜や音色確認用フレーズを表示
6. **PDF書出 / 印刷**: 「ファイル」タブの「書き出し」メニューで「PDF / 印刷」を選ぶとブラウザの印刷ダイアログが開く。送信先（プリンター選択）で「PDFに保存」を選べば、その場でPDFファイルとして保存できる

> 印刷プレビュー中は、確認モードとして譜面の編集（音符のクリック入力・削除・Undo/Redo など）ができません。余白・段の間隔・音符の大きさの調整と PDF 書出はプレビュー中でも操作できます。

### データの保存場所と安全性

つくった楽譜は、**この端末の中だけ**に保存されます。アプリの開発元やインターネット上のどこかへ送られることはありません。

- **自動保存の保存先**: いま使っているブラウザの保存領域（localStorage）です。同じ端末の同じブラウザで開いたときだけ、続きから編集できます。別の端末・別のブラウザ・他の人の画面からは見えません
- **ファイルの保存先**: 「書き出し」で作った `.score.json` や MusicXML は、保存のときにあなたが選んだフォルダに置かれます
- **印刷・PDF**: ブラウザの印刷機能をそのまま使うので、譜面がどこかへ送られることはありません
- **アカウント不要**: ログインや会員登録はありません。名前やメールアドレスをアプリへ渡す必要もありません

ブラウザの「閲覧履歴（サイトデータ）の削除」を実行したり、プライベートブラウジングで開いたりすると、自動保存の内容も一緒に消えます。**大事な譜面は「書き出し」でファイルとして保存しておいてください**（別の端末へ持ち運ぶときも、このファイルを使います）。

> 例外: 「開く」に「**PDF (β)**」ボタンが出ている場合、その機能だけは読み取りのために PDF を変換サーバーへ送ります（変換が終わると削除されます）。ボタンが出ていない環境では、この通信自体が行われません。

### 作品一覧の使い方

複数の曲をブラウザに保存しておき、切り替えながら編集できます。「ファイル」タブの「**作品一覧**」ボタンで開きます。

- **一覧**: 作品名と最終更新日時が、更新の新しい順に並びます。作品名が空のものは「無題」と表示され、最終更新日時で見分けられます
- **切り替え**: 作品名を押すとその作品が開きます。切り替える前にいまの内容は自動保存されるので、編集中の譜面が失われることはありません
- **新規作成**: 一覧の「新規作成」（「ファイル」タブの「新規作成」ボタンと同じ）で、いまの内容を保存してから新しい作品として空の譜面を開きます
- **削除**: 各行の「削除」で作品を消せます。取り消せないため確認ダイアログが出ます。いま開いている作品を削除したときは、画面は空の新規譜面に戻ります
- **復元履歴**: 各行の「履歴」で、その作品の過去の状態（自動で残る数世代。10分おきが目安・最大5世代）を開けます。「この時点に戻す」でその内容へ戻せます。**戻す直前の内容も1世代として残る**ので、誤って戻してもやり直せます
- アプリを開き直すとホーム画面が出て、「最近使ったファイル」の先頭から前回開いていた作品をそのまま開けます
- 同じ一覧はホーム画面の「最近使ったファイル」にも出ます（切替のみ。削除・復元履歴はこの「作品一覧」から行います）

## 5. よく使う応用操作

### 弦楽四重奏
- 「弦楽四重奏」ボタンを選択すると Vn. I / Vn. II / Va. / Vc. の 4 段譜面が表示されます（いちばん最初の段だけ Violin I / Violin II / Viola / Violoncello とフル名で表示されます）
- Viola 段はアルト記号（ハ音記号）が表示され、中央線が C4 になります
- 各段独立して音符を配置でき、再生ボタンで 4 パート同時に再生されます
- 「楽譜設定」タブの「パート名編集」ボタンで、各パートの正式名（1 段目に出る名前）と略称（2 段目以降に出る名前）を好みの表記に書き換えられます。書き換えた名前はパート譜表示の選択肢にも反映されます

### 編成譜
- 「編成譜」を選ぶと、編成テンプレートに沿った複数パート譜が表示されます
- 「編成」セレクトで室内オーケストラ、二管編成オーケストラ、吹奏楽などを切り替えられます
- 先頭システムの左側には、各パート名が表示されます。浄書の慣習にならい、譜面のいちばん最初の段だけフル名（Flute）で、2ページ目以降の先頭段は略称（Fl.）になります
- パート編集では、パート名、略称、楽器族、音部記号、移調、括弧グループ、サブ括弧を変更できます
- パート編集は「パート編集」ボタンからページ内のフローティングパネルで開き、総譜を見ながら編集できます（ポップアップブロック環境でも動作します）
- 括弧グループの `単独` は、ほかの単独パートと連続していても括弧でまとめません
- 各パートの再生音色を選ぶと、譜面全体再生時と音符入力時の確認音にそのパートの音色が使われます
- 「追加」「削除」「↑」「↓」でパート数と並び順を変更できます
- プリセットを編集すると `カスタム編成` として保存されます
- 移調楽器を含む編成では「実音」「記譜音」をワンクリックで切り替えられ、どちらのモードでも音符と調号を編集できます

### 和音入力
- **基本操作**: まず通常クリックで音符を配置し、その後 **同じ音符の上をクリック**（Y 位置が和音ゾーン内）で音を追加。Shift キーは不要
- **和音ゾーン**: 音符の描画 X 範囲（単旋律は左右 ±1.2px、ピアノ/複数パートは左右 ±1.5px）かつ五線 ± 3加線の固定 Y 範囲内がゾーン。ゾーン外のクリックは新規音符挿入になる
- **個別選択**: 和音内の既存音と同じ高さをクリックすると、その1音だけが青枠で選択される。符頭の上なら高さを少し（0.3ライン以内）外しても、いちばん近い音が選択される（2度でぶつかる和音の上の音も狙える）。音を追加したいときは、既存の音から半ライン以上離れた線・間をクリックする
- **音の移動**: 和音全体を選択しているときは矢印キー（↑/↓）で全音を同時シフト。和音内の1音を選択しているときは、その音だけを移動（`Alt` で半音、`Shift` でオクターブ）
- **選択する音符を変える**: ←/→ で、選択が同じ声部の前／次の音符・休符へ移ります。小節や段をまたいで移り、まだ何も書いていない小節は飛ばします。曲の最初・最後でさらに押したときは動かず、理由が画面下端に出ます（和音の中の1音を選んでいた場合、移った先では音符全体の選択に戻ります）
- **同じ高さへの移動**: 和音内の1音を、すでに同じ高さの音がある位置へ動かすと、同じ音が2つ重なる代わりに**1音にまとまります**（画面下端に「和音の1音にまとめました」と出ます。Cmd/Ctrl+Z で戻せます）。まとめたあとも選択はその音に残るので、続けて矢印キーで動かせます
- **音の削除**: 和音内の1音を選択して Delete / Backspace を押すと、その音だけを削除。最後の1音だけの場合は音符イベント全体を削除（連符の中に作った和音でも1音ずつ消え、連符グループはそのまま残ります。連符の中で最後の1音を消したときは、その位置が連符内の休符になります）
- **同時再生**: PolySynth が和音を1コールで同時発音。スコア再生時も全音が正確に再生される

### 自動休符補完
- **補完タイミング**: ある小節へ音符や休符を入れ始めたとき、その前にある未完成小節を拍子ぶんの長さまで休符で埋めます
- **休符編集時も補完**: 空小節や既存休符を音符へ置換・分割するときも、先に過去小節を補完してから譜面を再レイアウトします
- **対象範囲**: 編集中の小節そのものは触らず、それ以前の小節だけを補完します
- **クリックした拍まで埋める**: まだ音符が入っていない声部（ピアノ譜で声部2に切り替えた直後など）や、途中までしか書いていない声部で小節の**途中**をクリックすると、その拍まで手前を休符で埋めてから音符を置きます。たとえば声部1が埋まっている 4/4 の小節で声部2の2拍目をクリックすると、`4分休符 + 音符` になります（連符ツールでも同じです）。どこへ置いたかは「2拍目に置き、手前の空いた拍を休符で埋めました」のように画面下の中央へ数秒表示され、`Cmd/Ctrl+Z` で1回で戻せます。拍の位置は同じ小節のほかの声部・パートに並んでいる音符から決まるため、**その小節がどのパートも空のとき**は従来どおり小節の先頭に置かれます
- **複数パート譜**: 編成譜では、編集しているパートの過去小節だけを補完します。ほかのパートへ勝手に休符は入りません
- **拍が足りない小節の表示**: まだ埋まっていない拍には、薄いグレーの休符が見た目だけ表示されます（保存データには入りません）。その位置をクリックすればそのまま音符を置けます

### 臨時記号
- **パレット操作**: `♯ / ♭ / ♮ / ×（ダブルシャープ 𝄪）/ ♭♭（ダブルフラット 𝄫）` ボタンを選んだあと、対象の音符セルをクリックすると臨時記号を適用します
- **音価と同時に選んで一発入力**: `♩♯ / ♩♭ / ♩♮ / ♩× / ♩♭♭`（音符マーク付き）のボタンは、音価と**同時にONにしておくトグル**です。ONのあいだは譜面をクリックした1回で臨時記号付きの音符が入ります（付点・連符とも同時に使えます）。もう一度押すとOFF、休符ツール中にONにすると同じ音価の音符へ切り替わります
- **ダブルシャープ・ダブルフラット**: `×` は全音（半音2つ）上げ、`♭♭` は全音下げです。譜面には 𝄪 / 𝄫 の記号で描かれ、再生も全音ぶん上下します。付け外しは他の臨時記号と同じで、`♮` を選んで音符をクリックすれば元の音に戻ります
- **背景クリックでは挿入しない**: 臨時記号ツール中に小節背景をクリックしても、新しい音符は置かれません
- **和音への適用**: 和音をクリックした場合は、そのイベントに含まれる音すべてへ同じ臨時記号を適用します
- **半音入力**: キーボード派向けに `Alt + ↑/↓` の半音移動も引き続き使えます
- **ナチュラル表示**: 同じ小節内で先に変化していた同音名・同オクターブの音を自然音へ戻すと、ナチュラル記号（`n`）を自動表示します
- **重複抑制**: 同じ小節内で同じ臨時記号状態が続く場合、不要な `#` / `b` の重複表示を省きます
- **確認音の切替**: 音色詳細内のチェックボックスで、臨時記号を付けた直後の確認音を ON/OFF できます

### 微分音（四分音）の臨時記号
- **パレット操作**: `♯ / ♭ / ♮` の隣にある「四分音上げ（𝄲）」「四分音下げ（𝄳）」ボタンを選び、対象の音符セル（和音の場合は個別音）をクリックすると付与します。もう一度同じ音をクリックすると解除できます
- **通常の臨時記号と排他**: 四分音を付けるとその音の `♯ / ♭` は自然音へ戻り、逆に `♯ / ♭ / ♮` を適用するとその音の四分音は外れます（同じ音に両方が同時に付くことはありません）
- **再生（内蔵音源）**: クリック確認音（`NotePlayer`）は和音全体の四分音を反映して ±50セントのピッチシフトで鳴ります。譜面全体再生（`SimpleAudioEngine`）は先頭音（和音の1音目）のみ反映する既知の制限があります
- **再生（SoundFont）**: `soundfont-player` はセント単位のピッチシフト手段を持たないため、SoundFont 再生では四分音は半音に丸まって鳴ります（既知の制限）
- **対象外**: 3/4音（3 quarter tones）の記号は今回のスコープ外です

### 強弱記号
- **パレット操作**: `pp / p / mp / mf / f / ff / cresc. / dim. / descresc.` ボタンを選び、対象の音符セルをクリックします
- **descresc.**: `dim.` と同じ「だんだん弱く」の別表記です（実際の楽譜で使われる書き方に合わせるためのもので、表示される文字が違うだけで再生の音量変化は `dim.` と同じです）
- **解除方法**: 同じ強弱ボタンを選んだまま**音符**をもう一度クリックすると外せます。記号そのものをクリックして開く位置調整の「この記号を削除」ボタンでも消せます（記号のクリックは選択なので、押しても消えません）
- **共存ルール**: 絶対強弱（`p` など）と変化強弱（`cresc.` / `dim.` / `descresc.`）は同じ音符に併記できます
- **再生反映**: 再生ボタンの譜面全体再生では強弱記号をベロシティへ変換し、`cresc.` / `dim.` / `descresc.` は次の絶対強弱へ向かって段階的に増減します
- **音符との自動衝突回避**: 低い音符の加線や下向きの符幹に重なるときは、記号が自動で少し下へ避けて表示されます。✥（位置調整）で手動調整した記号は自動では動きません（手動の指定が常に優先）
- **避けきれないとき**: ピアノ譜のような多段譜では、記号は**下の五線の手前まで**しか下がりません（市販譜と同じで、強弱記号は五線と五線の間に収めます）。そのため音符と少し重なったまま止まることがあります。重なりが気になるときは、レイアウトタブの「パート間隔」を広げると記号の逃げ場が増えて自然に解消します（✥ で個別に動かすこともできます）
- **字形**: `pp`〜`ff` は市販譜と同じ専用の記号フォント（音符と同じ Bravura）で表示されます。`cresc.` / `dim.` / `descresc.` は文字表記のままです

### 松葉（ヘアピン、クレッシェンド＜／デクレッシェンド＞）
- **パレット操作**: 「演奏記号」タブの `＜`（cresc.）/ `＞`（dim.）ボタンを選び、開始音符から終了音符へドラッグして設置します（タイ/スラーと同じ操作系）
- **表示位置**: 五線の下、強弱記号テキストと同じ高さ帯に描画されます。小節またぎ・段またぎに対応します
- **削除方法**: 描画済みの松葉をクリックすると青くハイライトされ、Delete / Backspace キーで削除できます（Escape で選択解除）
- **再生反映**: テキストの `cresc.` / `dim.` と同じ扱いで、次の絶対強弱へ向かって段階的にベロシティが増減します

### アーティキュレーション（奏法記号）
- **パレット操作**: `•`（スタッカート）/ `>`（アクセント）/ `‒`（テヌート）/ `^`（マルカート）/ `𝄐`（フェルマータ）ボタンを選び、対象の音符セルをクリックします
- **解除方法**: 同じボタンを選んだまま同じ音符をもう一度クリックすると、その記号を外せます（トグル）
- **重ね付け**: スタッカート＋アクセントのように、種類が違う記号は同じ音符に重ねて付けられます
- **休符には付かない**: 奏法記号は「鳴らし方」の指示なので、休符には付きません（休符をクリックすると、記号は付かず「音符をクリックしてください」という案内が画面に出ます）
- **再生反映**: 譜面全体再生では、スタッカート＝音を短く / アクセント・マルカート＝音を強く / フェルマータ＝長く伸ばす、として音の長さ・音量へ変換します（複数付いていれば倍率を掛け合わせます）

### タイ／スラー
- パレットのタイボタンを選択し、開始音符から終了音符へドラッグして設置します。同音はタイ、異音はスラーとして自動判定され、小節またぎ・段またぎにも対応します
- 描画済みの弧は**中央（頂点）付近をクリック**すると青くハイライトされます（端点付近は音符のクリックを優先するため反応しません）。掴める場所にカーソルを乗せると弧が薄くなるので、押す前に分かります。弧の中央付近をドラッグすると曲率が、丸いハンドルをドラッグすると接続位置が変わります。音符の反対側まで引っ張ると弧の向きが反転します
- 選択すると頂点に**四角いハンドル**が出ます。上下にドラッグすると膨らみ、左右にドラッグすると頂点の位置（弧の一番高いところを左右どちらへ寄せるか）が変わります。左右の寄せ幅は弧の長さの ±15% までです
- ドラッグは**五線の外まで大きく引っ張っても続き**、指を離した位置で確定します。確定するまで譜面は動きません。途中で **Escape** を押すと、掴む前の形に戻して中止できます（弧の選択は残るので掴み直せます）
- 弧の向きは音符の高さから自動で決まります。ただしピアノ譜で声部1と声部2の両方を使っている小節では、楽譜の慣習に合わせて**声部1（上声）の弧は上向き・声部2（下声）の弧は下向き**に固定されます（符幹の向きと同じ考え方です）。手動での反転は従来どおりできます
- 2声部の小節で弧が符幹と同じ側を通るときは、弧の端が**符幹の先端側**に付き、符頭・符幹・ビームの外側を通ります。手動で向きを反転して弧が符頭側へ回ったときは、従来どおり符頭に付きます
- **再生反映**: タイで結ばれた音は、譜面全体再生でも**1音として**（合計の長さで）鳴ります。3つ以上つないだ場合も合計の長さになります。スラー（違う高さを結ぶ弧）は従来どおりそれぞれ発音します。タイの後ろ側の音に付けたアーティキュレーションは再生には反映されません（1音として鳴るため。開始音の記号が全体へ効きます）。なお、リピートで「次の小節」が変わる箇所をまたぐタイと、タイの後ろ側の小節から途中再生した場合は、音が消えないようそれぞれ別の音として鳴ります
- Delete キーでは弧だけが消え、音符は残ります（Escape で選択解除）

### リピート記号
- **パレット操作**: `||:` で開始リピート、`:||` で終了リピートを選びます
- **配置方法**: 記号を置きたい小節の背景または音符セルをクリックすると、その小節線にリピート記号が付きます
- **解除方法**: 同じ記号ツールを選んだまま、同じ小節をもう一度クリックすると外せます
- **両方配置**: 同じ小節に `||:` と `:||` を別々に付けることもできます
- **再生反映**: `||:` から `:||` までは、譜面再生時に 1 回だけ折り返して再生します
- **開始記号省略**: `:||` だけ置いた場合は、譜面の先頭からその小節までを折り返します
- `1.` / `2.` ボタンで、対象小節に1番括弧／2番括弧を付けられます。再生では1周目は1番括弧、2周目は2番括弧だけが鳴ります

### 調号
- **調号選択**: ツールバーの `調号` セレクトで、調号なし / ♯系 / ♭系の調号ファミリーを選べます
- **行頭クリックでも変更**: `♯ / ♭ / ♮` ツールを選んで各段の行頭をクリックすると、調号を1段ずつ増減できます。`♮` は調号なしへ戻します
  拍子記号がある段では、その右側から音符の手前までを調号クリック領域として扱います
  `♯ / ♭ / ♮` ツール中は、調号クリック領域を薄いオレンジ色で表示し、クリック時にブラウザコンソールへ診断ログを出します
  既存の音符セルを押したときは常に臨時記号、音符の無い小節背景の調号領域を押したときだけ調号として扱います
  `♯` はシャープ系の調号を、`♭` はフラット系の調号を増やしていき、別系統へ切り替えるときはまず `♯1つ` / `♭1つ` から始めます
  初期表示の全休符は見た目だけのガイドとして描画し、巨大な編集ヒット領域は持たせません
- **表示位置**: このエディタでは先頭行の調号を拍子記号の右側へ表示します
- **入力への反映**: 調号に含まれる音は、新規入力や通常の上下移動で既定の `f#` や `bb` を自動反映します
- **表示の省略**: たとえば G 系（♯1つ）で `f#/4` を置いた場合、臨時記号は毎回は出ず、調号に含まれる音として扱います
- **ナチュラル表示**: 調号で `F#` が既定のときに `f/4` を置くと、必要な位置にだけナチュラルが表示されます

### 拍子を記号（C / 𝄵）で表示する
- 「楽譜設定」タブで拍子に `4/4` か `2/2` を選ぶと、隣の「記号で表示（C / 𝄵）」が押せるようになります
- チェックを入れると、`4/4` は `C`、`2/2` はアッラ・ブレーヴェ（縦線入りの `C`）で描かれます。印刷プレビュー・PDF 書き出しも同じ見た目になります
- 拍子そのものは変わりません（`2/2` のままなので、1小節に入る音符の量も再生も同じです）
- 記号があるのは `4/4` と `2/2` だけなので、`3/4` や `6/8` を選んでいる間はチェックできません

### 曲の途中で拍子・テンポ・調号・音部記号を変える
- 「演奏記号」タブの「拍子変更」「テンポ変更」「調号変更」「音部記号変更」ツールを選び、変えたい小節をクリックすると、その場に入力欄やドロップダウンが開きます
- 「テンポ変更」で入れた数値（♩=XXX）は、その小節から再生の速さにも反映されます。同じ小節に速度標語（Andante 等）も置いている場合は、数値のほうが優先されます
- いずれも「解除」または空欄での確定でその小節の指定を外せます。指定した内容は次の変更があるまで後続の小節へ引き継がれます
- 音部記号は**小節の途中からでも変えられます**。「音部記号変更」ツールを選び、小節の背景ではなく**変えたい音符をクリック**すると「この音から音部記号を変更」のドロップダウンが開き、その音符の直前に小型の音部記号が入ります（月光第1楽章37小節のように、右手が小節の途中でヘ音記号へ移る書き方）。変えた音部記号は次の変更まで、小節をまたいで続きます
- 小節の途中からの変更は**声部1の音符にだけ**付けられます（声部2の音符をクリックしたときは、その旨をお知らせします）
- 「リハーサルマーク」ツールでは、小節をクリックすると次の連番（A→B→…）が自動提案され、四角枠付きで小節の左上に表示されます

### 音符に紐づかない文章を置く（自由注釈テキスト）
- 「演奏記号」タブの「T」（自由注釈テキスト）ツールを選び、置きたい小節をクリックすると入力欄が開きます
- 文章・書体・文字サイズ（％）・位置（横・縦の px）を入力し、Enter か「確定」で譜面に置かれます。既定ではイタリックのセリフ体で五線の上に表示されます
- **書体**はタイトルと同じ一覧（明朝・ゴシック・Webフォントなど）から選べます。「既定（イタリック・指示文向き）」のままなら従来どおりの見た目です。書体を選ぶとイタリックは外れ、その書体そのものの形になります
- 入力欄が開いている間は、**矢印キーで文章を1pxずつ動かせます**（Shift+矢印で10pxずつ。文章・文字サイズ・横・縦の入力欄で効きます。書体の選択リストでは矢印キーは書体の選択に使われます）。動かすと譜面の文章がその場で動き、横・縦の数値も一緒に変わります。位置が決まったら Enter で確定です
- 大譜表では**クリックした段**に置かれます。右手の五線の上と左手の五線の上に、別々の文章を置けます
- 置いた小節が動く（段あたり小節数を変えるなど）と、文章も同じ小節に付いて移動します
- 消すときは同じツールでその小節をクリックし、文章を空欄にして確定します
- 「演奏記号」タブを開いている間は、**置いた文章そのものをクリック**しても同じ編集が開きます（他の記号のクリック選択と同じ扱いです）

### 重なっているものを選び分ける（同じ場所の再クリック）
- スラーの弧と途中の符頭のように**当たり判定が重なっている場所**では、1回目のクリックは従来どおり手前のものが選ばれます
- **同じ場所をもう一度クリックすると、その下にある次の対象へ切り替わります**（音符 → スラー → 松葉 → …）。一巡すると先頭へ戻ります。候補を選ぶポップアップは出ません
- 数px 以上離れた場所をクリックすると、そこから 1 回目のやり直しになります
- 重なっていない場所では何も変わりません。休符を音符に置き換える操作や、奏法記号をもう一度押して外す操作も従来どおりです

### 小節を選ぶ
- 「音符・休符」タブの「小節選択」ツールに切り替えると、小節をクリックして選べます。**小節Aで押したまま小節Bまでドラッグすると、A〜Bをまとめて範囲選択**できます（`Shift+クリック`で範囲を広げる従来の操作も使えます）。小節の端から端までを覆うドラッグは従来どおり小節丸ごとの選択になり、**小節の途中の拍で始めたり止めたりすると「拍の範囲」の選択**になります（次の項）
- **音符ツールなど他のツールを選んだままでも、小節を `Shift+クリック` すれば小節選択になります**（音符は置かれません）。コピー＆ペーストのためだけにツールを持ち替える必要はありません。選択済みの状態で別の小節を `Shift+クリック` すると範囲が広がります
- 選択中の小節は青い枠と薄い青の塗りで示されます。この色は画面上だけのもので、印刷・PDF書出には出ません
- 選択を解除するには `Escape` を押します
- 複数パートの譜面（ピアノ・弦楽四重奏・編成譜）では、選んだ小節位置の全パートが同時に選択されます

### 拍の範囲を選んでコピー・削除・貼り付け（部分コピペ）
- 「小節選択」ツールのドラッグを小節の**途中の拍**で始めたり止めたりすると、小節丸ごとではなく**拍の範囲**が選ばれます。選択範囲は薄い青の帯で示されます
- **ピアノ譜では、選択中のレイヤー（手×声部）だけが対象です**。切れ目の吸着・コピー・貼り付け・削除のすべてがそのレイヤーにだけ効き、もう片方の手は巻き込みません（繰り返すパーツを片手だけコピーする使い方のため）。貼り付け先は**貼り付けたときに選んでいるレイヤー**なので、右手でコピーして左手へ貼ることもできます
- 単旋律・弦楽四重奏・編成譜では従来どおり、全パートの同じ拍範囲（縦のスライス）が同時に対象になります
- 端は自動で「対象になる声部の音符の切れ目」へ吸着します（音符や連符を途中で割る位置は選べません）。切れ目が小節の頭と末尾しか無い小節では、実質小節丸ごとの選択になります
- `Cmd/Ctrl+C` で選択範囲をコピー、`Delete` で範囲を休符に置き換え、`Cmd/Ctrl+V` で選択位置へ上書き貼り付けできます。貼り付けは**コピーした幅ぶん**を上書きします（コピー元の無音部分も無音として貼られます）
- 貼り付けると選択が**貼った範囲のすぐ後ろ**へ自動で進むので、`Cmd/Ctrl+V` を押すだけで同じパーツを連続で並べられます（小節の終わりまで来たら次の小節の頭へ進みます。繰り返し音型の入力に便利です）。複数の小節にまたがる長いコピーでは選択は進みません
- コピーした内容は同じ楽器（パート）どうしで貼り付きます。コピー後に譜面の種類や編成を変えた場合、対応するパートが無ければその部分は貼られません
- 収まらない・音符の切れ目に合わない・何も変わらない、などで貼り付けや削除ができないときは、理由が画面下部に表示されます
- **既知の制限**: スラー・タイ・松葉（クレッシェンド等）はコピーに含まれません（貼り付け先には付きません）。複数小節にまたがるコピーは、内容が途切れないよう**コピー元と同じ小節内の位置**にだけ貼り付けられます。また拍の範囲を選択中は、小節単位の操作（移調・小節の挿入/削除・小節丸ごとの貼り付け・矢印キーでの選択移動）は使えません（ボタンが無効になり、理由がツールチップと通知で示されます）

### 小節の挿入・削除、選択範囲の移調
- 「小節選択」ツールで小節を1つ選ぶと、「小節を挿入」「小節を削除」ボタンが使えます。複数パートの譜面では全パートに同時に適用されるため、パート間で小節数がずれることはありません
- 小節（範囲）を選択すると、「音符・休符」タブに「移調」ボタンが現れます。半音上/下・全音上/下・オクターブ上/下の6ボタンと「半音数指定」（-12〜+12）で選択範囲をまとめて移調できます
- 移調結果が対応音域を外れる音が1音でもある場合は、操作全体を中止してエラーメッセージを表示します（部分的には適用されません）

### 8va / 8vb（オッターバ）
- 「演奏記号」タブの「8va」（または「8vb」）で範囲の**最初の音符**をクリックし、「8va終了」で**最後の音符**をクリックすると、点線の括弧が表示されます。開始と終了がそろって初めて描かれるため、片方だけの間は画面に出ません（その旨を画面下の通知で案内します）。もう一度同じ音符をクリックすると外せます
- 括弧は範囲内の音符や、上に動かした強弱記号などと重ならないよう自動で外側へ逃げます。「✥」で手動調整した場合は自動では動きません
- 範囲が段をまたぐ場合は、前の段では右端まで（縦線なし＝続きの印）、次の段では左端から続きの括弧が描かれます

### スラー・松葉を選択しているとき
- スラー／タイ・松葉（＜＞）をクリックで選択している間、**矢印キーは何もしません**（形の調整はドラッグで行います）。Delete で削除、Esc で選択解除です

### カスタム記号と、記号のサイズ・位置調整
- 「演奏記号」タブの「＋」ボタンで記号エディタを開き、フリーハンド・直線・円・弧を組み合わせてオリジナルの記号を作れます。作った記号はパレットに並び、音符へトグルで付け外しできます
- 「⤢」（サイズ変更）・「✥」（位置調整）ボタンを押してから音符をクリックすると、その音符に付いている記号の大きさ（25〜400%）や位置（横・縦 -100〜100px）を1件ずつ調整できます。休符でも、歌詞・コード記号・テンポ表記・発想標語・オッターバのように休符に付けられる記号なら同じように調整できます（運指・強弱・アーティキュレーションは音符専用です）
- サイズの％は「既定の大きさに対する倍率」です。運指（指番号）の既定サイズは読みやすさのため従来の180%に拡大したので、それ以前に運指へ「⤢」でサイズを設定していた譜面では、その％のぶんだけさらに大きく表示されます（大きすぎる場合は「⤢」で100%に戻してください）
- 「音符・休符」タブの「⇵」（段またぎ表示）ボタンを押してから音符をクリックすると、その音符だけを隣の五線に描き移せます（右手の音は下の五線へ、左手の音は上の五線へ）。加線が何本も必要になる音を読みやすく書くための、ピアノ譜の書き方です。もう一度同じ音符をクリックすると元の五線に戻ります。音の高さ・リズム・再生は変わりません。五線が2段あるピアノ譜でだけ使えます（それ以外の譜面ではボタンがグレーアウトします）
- **「演奏記号」タブを選んでいる間は、記号そのものをクリックするとその記号を選べます**（押しても消えません。「⤢」を選んでいるときだけサイズ変更の入力欄が開きます）。**別のレイヤー（右手/左手 × 声部1/2）の記号でもそのまま押せます**——その場合はレイヤーが自動でそちらへ切り替わり、「左手・声部1に切り替えました」のように画面に出ます（どの記号がどの声部のものかは見た目では分からないため、レイヤーを合わせ直す手間をなくしています）。開いた位置調整の入力欄には「この記号を削除」ボタンがあります（歌詞だけは直接クリックにまだ対応しておらず、「⤢」「✥」ボタンから音符をクリックして調整します）。「音符・休符」タブなど他のタブでは記号はクリックを受けないので、記号の重なった位置にもそのまま音符を置けます（Finale などと同じく、クリックの意味は選んでいるタブ・ツールで決まります）
- 位置調整の入力欄が開いている間は、**矢印キーで記号を1pxずつ動かせます**（Shift+矢印で10pxずつ）。動かすと譜面の記号がその場で動き、入力欄の数値も一緒に変わります。**矢印キーを押している間は入力欄が半透明になり**、周りの音符と見比べながら位置を合わせられます（キーを止めるか、入力欄にカーソルを乗せると元に戻ります）。Enter または欄の外をクリックで確定、Esc で開いた時点の位置へ戻ります。矢印キーで何回動かしても、確定したぶんは「元に戻す」1回でまとめて取り消せます
- 位置調整の入力欄が開いている間は、**その記号そのものをマウスでドラッグしても動かせます**（大きく動かすのはドラッグ、細かく合わせるのは矢印キー、という使い分けです）。掴める記号にカーソルを乗せると手の形（掴めるカーソル）に変わります。指を離した時点で確定し、動かしたぶんは「元に戻す」1回で取り消せます。少し押しただけ（ほとんど動かさなかったとき）は、これまでどおり「記号を選んだ」だけの扱いです
- サイズ変更・位置調整の入力欄は、**調整している記号に重ならない位置**（ふだんは記号の上、画面上端に近いときは下）に開きます。位置は開いたときに決まり、矢印キーで記号を動かしている間も動きません
- サイズ・位置の入力欄を開いたまま別のツールを選ぶと、入力欄は閉じて Esc と同じく開いた時点の値へ戻ります（確定はされません）。切り替えた直後の音符クリックは、そのまま新しいツールの操作として効きます

### 🎵 音符再生
1. **個別再生**: 配置した音符をクリックして音を確認
   単旋律やピアノ譜では現在選んだ楽器音色に追従し、編成譜ではクリックしたパートの再生音色で確認できます
2. **全体再生**: ツールバーの再生ボタン（▶️）で譜面全体を再生
   **小節を選択したまま再生すると、その小節から再生されます**（「◯小節目から再生します」と画面に出ます。先頭から聴くには `Escape` で選択を外してください。リピートがある譜面では、その小節が最初に鳴る位置から始まります）
   再生中は、いま鳴っている位置に**淡い橙色の縦帯**が出ます。帯は段の上から下までを貫くので、大譜表や編成譜でも全パートの同じ位置がひと目で分かります。停止・一時停止・別タブへの切り替えで消えます
3. **小節番号を指定して再生**: 「再生・音色」タブの右端にある「小節番号」に数字を入れて「この小節から再生」を押すと（入力欄で `Enter` を押しても同じです）、その小節の頭から鳴ります。長い曲で、聴きたい小節まで画面をスクロールして選択しなくても頭出しできます。開始位置より前に置いたテンポ・速度標語・強弱記号は、小節を選んで再生したときと同じように引き継がれます。1 より小さい番号や小節数を超える番号を入れたときは、理由が画面に出て再生は始まりません。再生中に指定したときは、いったん止めてからその小節で鳴らし直します
4. **音色確認**: スピーカーボタン（🔊）で現在の音色をプレビュー
5. **音源方式切り替え**: 必要に応じて `内蔵音源` と `SoundFont` を切り替える
6. **再生速度**: 「再生・音色」タブの「再生速度」スライダーで、譜面はそのままに**聴くときの速さだけ**を 25〜200% で変えられます（既定は 100%＝楽譜どおり）。ゆっくりにしても曲の中のテンポの変化（♩=N や Allegro などの速度標語）の関係はそのまま保たれます。楽譜・保存データ・書き出したファイルは変わりません。「等倍に戻す」ボタンでいつでも 100% に戻せます
7. **作品の基準テンポ**: BPM設定は、譜面にテンポを書いていない部分で使う**その作品の基準の速さ**です（30〜240 BPM。範囲の外の数値を入れると近いほうの端に合わせ、その旨が入力欄の下に表示されます）。譜面に ♩=N や速度標語を書いた小節では、そちらが優先されます。テンポは**作品ごとに覚えます**。作品一覧で別の作品へ切り替えたり、保存したファイルを開き直したりすると、その作品で設定していたテンポに戻ります（テンポを設定したことがない作品は、直前に使っていたテンポのまま開きます）
8. **スウィング再生**: 「音色詳細」のトグルをONにすると、記譜はそのままで8分音符だけが2:1で跳ねて鳴ります
9. **余韻の長さ**: 「音色詳細」の「余韻」スライダーで、音を鳴らし終わったあとに残る**尻尾の長さ**（0.3〜0.6秒）が変わります。実際のピアノと同じように、音価どおりの位置で切らずに少し伸ばして消えるので、2分音符・全音符が短く聞こえにくくなります。伸びるのは音の終わりだけで、**テンポやリズム（次の音が鳴る位置）は変わりません**。速いパッセージが濁らないよう、短い音符の尻尾は音符自身の長さまでに抑えられます

### パート譜・他のソフトとのやりとり
- 弦楽四重奏・編成譜では、「ファイル」タブの「パート譜表示」から1パートだけを抜き出した譜面を表示・印刷できます
- パート譜を見ながらそのまま音符の入力・削除に加えて、**記号・アーティキュレーション（強弱・タイ/スラー・臨時記号など）の編集**もでき、総譜へ戻ると同じ変更が反映されています（移調楽器を記譜音で表示しているときは、入力・編集した音高が自動で実音に直されて保存されます）
- パート譜の改行位置（1段に入る小節数）は、**抜き出したパート単体の音符の詰まり具合で自動計算**されます。総譜では他パートの音符が密集していて改行が細かくなっていても、パート譜では市販のパート譜のように詰めて表示・印刷されます（総譜で行った段ごとの小節数の手動調整はパート譜には効かず、総譜へ戻るとそのまま復元されます）
- ピアノなど上下2段の大譜表パートのパート譜は、いまのところ閲覧・印刷専用です（ヘッダーに「閲覧・印刷専用」と表示されます）
- 「書き出し」メニューの「MusicXML」と「開く」の「MusicXML (.mxl)」ボタンで、他の楽譜ソフトとの受け渡しができます。「書き出し」→「MIDI」では MIDI Type 1 ファイルを書き出せます
- 「書き出し」で形式（ファイル (.score.json) / MusicXML / MIDI）を選ぶと、**ファイル名を入力する画面**が出ます。はじめは譜面のタイトルが入っているので、そのままでよければ Enter か「書き出す」を押してください。別の名前にしたいときは書き換えてから書き出します（拡張子はアプリが付けるので、入力欄には書かなくて構いません）。Chrome でも Safari でも同じ操作です（PDF / 印刷はブラウザの印刷ダイアログで名前を決めるため、この画面は出ません）
- 書き出しの結果は画面の右下に数秒表示されます。書き出せたときは「✓ MusicXMLを書き出しました」（MIDI も同様）、書き出せなかったときは赤い「⚠ MusicXMLを書き出せませんでした」と、その理由が出ます
- 不具合を見つけたときは、タブ行右端の「💬 フィードバック」ボタンで現在の譜面と設定をクリップボードへコピーし、GitHub の Issue 作成画面を開けます（どのタブからでも押せます。ツールバーを折り畳んでいるときも最下段から押せるので、報告のために折り畳みを解除する必要はありません。譜面の内容が公開リポジトリへ投稿される点にご注意ください）

## 6. キーボードショートカット

| キー | 動作 |
| --- | --- |
| `1`〜`7` | 音価の選択（3=十六分、4=八分、5=四分、6=二分、7=全音符） |
| `R` | 現在の音価のまま休符モードを切り替え |
| `.` | 付点の ON / OFF |
| `V` | ピアノ譜の声部1 ↔ 声部2 の切り替え |
| `↑` / `↓` | 選択中の音符の音高を上下（和音全体を選択中は全音を同時に移動） |
| `Alt + ↑/↓` | 半音単位で移動 |
| `Shift + ↑/↓` | オクターブ単位で移動 |
| `0` | 選択中の休符を標準位置へ戻す（2声部が共存する小節では声部1＝やや上／声部2＝やや下、それ以外は音価どおりの位置） |
| `Delete` / `Backspace` | 選択中の音符・和音内の1音・弧・松葉を削除。何を消したかが画面下の中央に数秒表示されます（例:「音符を削除しました（Cmd/Ctrl+Z で元に戻せます）」）。連符の中の音符は、その位置が連符内の休符になります（下の「連符の中の音符を消す」を参照） |
| `Escape` | 選択を解除する／入力欄をキャンセルする |
| `?` | ヘルプ（操作の説明書）を開く |
| `←` / `→` | 音符を選択しているときは、選択を同じ声部の前／次の音符・休符へ移す（小節や段をまたいで移り、まだ何も書いていない小節は飛ばします。曲の端では動かず、画面下端に理由が出ます）。音符を選んでいないときは小節選択を左右に移動（`Shift` を足すと範囲を広げる） |
| `Cmd/Ctrl + C` / `Cmd/Ctrl + V` | 選択した小節のコピー／貼り付け。小節を選んでいないときに連符（3連符など）の音符を選んで押すと、その連符グループのコピー／小節の空きへの貼り付けになります。スラー・タイ・松葉は貼り付け先に合わせて自動でつなぎ直されます（ただし**コピーした範囲の外へ伸びていたもの**は、つなぐ先の音符が貼り付け先に無いため付きません。その場合は何件付かなかったかを画面下に表示します） |
| `Cmd/Ctrl + Z` | 元に戻す |
| `Cmd/Ctrl + Shift + Z` または `Cmd/Ctrl + Y` | やり直す |
| `Cmd/Ctrl + Shift + ↑/↓` | 選択した小節を半音単位で移調 |

はじめて音符を選んだときに、`↑↓`・`←→`・`Delete` があることを画面下の中央で一度だけお知らせします（一度見たら次からは出ません。この表からいつでも確認できます）。

テキスト入力中と印刷プレビュー中は、これらのショートカットは無効になります（例外: `?` のヘルプは閲覧操作のため、印刷プレビュー中でも開けます）。

## 7. 既知の制限とトラブル対処

### 既知の制限

- **ピアノ譜の声部2**: タイ/スラー・松葉は、いま編集している側の声部でだけ張ったり掴んだりできます（声部1に切り替えているあいだ、声部2の弧・松葉はクリックしても選べません。声部を切り替えると選択は外れます）。声部をまたいで1本の弧を張ることはできません。声部2の弧・松葉は、編集していない側でも薄いグレーにはならず黒のまま表示されます。連符（2/3/4/5/6/7連符）・和音の1音だけの削除・音高の移動（矢印キー）・休符の位置リセット（0キー）・記号のサイズ/位置調整・テキスト要素（歌詞・運指など）は声部2でも使えます。MusicXML の書き出し・読み込みは、音符・休符と松葉のどちらも声部2に対応しています
- **微分音（四分音）**: 譜面全体再生では和音の1音目だけに反映されます。SoundFont 再生では半音に丸まって鳴ります
- **装飾記号**: トリルは譜面全体の再生で主音と上隣接音の交互連打として鳴ります。モルデント・プラルトリラー・ターン・前打音は表示のみで、再生音への反映には未対応です
- **途中の調号変更**: 旧調号を打ち消すナチュラルのキャンセル表示には対応していません
- **途中の音部記号変更**: MusicXML の書き出し・読み込みの両方に対応しています（小節の頭からの変更も、小節の途中からの変更も、書き出し・読み込みで保たれます）
- **MusicXML のテンポ**: テンポ（♩=N）は書き出し・読み込みの両方に対応しています。再生パネルのテンポ、小節ごとのテンポ変更、候補から選んだ速度標語（Andante 等）の目安テンポが書き出され、読み込むと同じ速さで再生されます（候補に無い言葉を自由入力した速度標語は、これまでどおり文字だけが受け渡されます）
- **MusicXML の強弱記号**: 文字の強弱（pp・p・mp・mf・f・ff）と松葉（クレッシェンド／ディミヌエンド）は書き出し・読み込みの両方に対応しています（声部2に置いたものも含みます）。これ以外の強弱記号（sfz・fp・ppp など）は取り込まず、読み込み後に「未対応の強弱記号 N 件は取り込めませんでした」とお知らせします（近い記号へ勝手に置き換えないためです。読み込み自体は成功します）
- **MusicXML のタイ／スラー**: 弧（タイ・スラー）は MusicXML に書き出されません（声部1・声部2のどちらも同じです）。MusicXML で受け渡すと弧は失われるので、弧を保ったまま持ち運ぶときは「書き出し」→「ファイル (.score.json)」を使ってください
- **MusicXML の互換**: このアプリ自身が書き出したファイルとの往復を優先しているため、他ソフトが出力したファイルの完全な互換は対象外です。他ソフト（Finale・MuseScore など）が書き出すピアノ譜は「1つのパートに上下2段の五線」という形式が主流ですが、これは読み込み時に右手・左手へ自動で振り分けます
- **MusicXML のレイアウト**: 読み込むファイルが音符の大きさ・用紙サイズ・ページ余白の指定を持っている場合（Finale・MuseScore などの書き出しには通常入っています）、その指定でその作品を開きます。指定どおりでは紙幅に収まらない小節があるときは、収まる大きさまで自動で下げ、画面右下でお知らせします。読み込んだあとはレイアウトタブでいつでも変えられます（変えた値はその作品といっしょに保存されます）
- **再生位置のシーク**: 再生位置をクリックして途中から鳴らす操作には未対応です
- **SoundFont**: 音色サンプルは初回再生時に外部 CDN から取得するため、オフラインでは SoundFont 音源が鳴りません（内蔵音源は鳴ります）
- **多段譜の段の間のクリック**: 段と段の間をクリックしたときは、**近いほうの五線**に音符が入ります。そのため、上の段へ何本目の加線まで直接置けるかは「パート間隔」（レイアウトタブ）の広さで決まります（弦楽四重奏の既定では下第2加線まで、編成譜の既定では下第1加線まで、ピアノの既定では下第3加線まで）。それより外の音を置きたいときは、いったん置いてから ↑ / ↓ キーで動かすか、パート間隔を広げてください
- **長い発想標語**: 折り返しには未対応です。小節幅より長い標語（例: 月光冒頭の "Si deve suonare..."）は右へはみ出して表示されます（左は紙面から切れないよう五線の左端で止まります）。気になるときは演奏記号タブの位置調整（✥）でずらしてください
- **コード記号**: 譜面には表示されますが、MusicXML には書き出されません（MusicXML で受け渡すとコード記号は失われます）
- **段またぎ記譜（右手の音を下の五線に描く）**: MusicXML には書き出されません（書き出すと元の五線に戻ります）。パート譜表示中は相手の五線が無いため、そのパート自身の五線に描かれます
- **パート譜表示中**: 改行位置はパート単体の内容から自動計算されます（手動での調整と、その保存には未対応です）。音符の入力・削除、記号・アーティキュレーションの編集は対応済みです。大譜表（上下2段）パートのパート譜は閲覧・印刷専用です

### 音が鳴らない（特に Safari）

- Safari では、別タブでの動画再生やタブ復帰のあとに `AudioContext` が不安定になり、無音になることがあります。アプリが無音を自動検知して復旧を試み、通知を表示します
- 自動で戻らないときは「**音声復旧**」ボタンを押してください（既定の再生設定＝標準の音源（SoundFont）・ピアノ・既定プロファイルへ安全に戻します）
- 無音の通知には**現在の音声出力先のデバイス名と確認手順**が併記されます（取得できる環境のみ）。診断が正常なのに聞こえない場合は、パソコン側の出力先（メニューバーの音量→出力先）が別のモニター等へ向いていないか確認してください
- SoundFont の読み込みに失敗したときは、その操作だけ一時的に内蔵音源へ切り替わり、再生パネルに「いま鳴っている方式」が表示されます

### 「⚠ あふれます」と出る／段が紙に収まらない

- 「段数/ページ」に紙面へ入りきらない値を指定すると警告が出ます。指定どおり描画はされるので、そのまま使うか、値を下げるか、レイアウトタブの「音符の大きさ」「段の間隔」を小さくして調整してください
- 「段あたり小節数」「段数/ページ」は楽譜の種類ごとに別々に覚えます。単旋律で 8小節/段 にしても編成譜には影響せず、種類を切り替えるとその種類で最後に使った値へ戻ります
- 「段数/ページ」の初期値は楽譜の種類ごとの推奨値です（ピアノはページに収まる限り常に4段。自分で保存した値があればそちらが優先されます）
- 大編成の編成譜では、1段が紙に収まらない場合に音符の大きさが自動で縮小され、「（紙面に収めるため実際は◯◯%で表示）」と表示されます

### 譜面が消えた・元に戻したい

- 編集は自動保存されており、リロードすると直前の内容から再開できます。別の曲を編集していた場合は「ファイル」タブの「作品一覧」から戻せます。過去の状態へは各作品の「履歴」（復元履歴）から戻せます。以前の手動「保存」のデータが残っている場合は、「開く」の「以前の手動保存」ボタンで作品として取り込めます
- 直前の操作は `Cmd/Ctrl + Z` で取り消せます（最大50件）

### 「書き出し」→「ファイル」で選んだ場所にファイルができない

- 環境によっては、保存先を選べても書き込みが許可されないことがあります。その場合はブラウザのダウンロードに保存され、画面右上に「選択した場所へ書き込めなかったため、ダウンロードに保存しました」と表示されます。譜面はダウンロードフォルダの `.score.json` に入っているので、「開く」の「ファイル」ボタンから読み込めます
- 通知に「選択先にできた空のファイルは削除してください」と続く場合は、保存先に中身のない0バイトのファイルが残っています。本物と取り違えないよう削除してください
