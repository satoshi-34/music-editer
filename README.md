🎼 Music Editor MVP
Finale ライクな楽譜作成アプリを目指した Web アプリの最小構成（MVP）です。
React + TypeScript + Vite + VexFlow を使って、五線譜へクリックで音符を配置できます。
MuseScore っぽい小節幅の自動割り付けと、クリック位置の高精度スナップ（線バイアス付き）を搭載。
🚀 機能概要
⚛️ React + TypeScript + Vite による高速開発
🎼 ト音記号 + 4/4 拍子の五線譜表示（段の自動レイアウト）
🖱 クリックで音符/休符を配置（加線域を含む上下方向も正確）
🧠 小節幅の自動割り付け（全・二分は広め／細かい音符は過密回避）
✂️ 既存音符の見た目の位置に基づく挿入（getAbsoluteX() 利用）
🧰 Palette から音価や休符を選んで配置（四分・八分・十六分…）

🎹 使い方（超かんたん）
画面上の Palette で音価（四分・八分・十六分…）や 休符 を選ぶ
五線譜の置きたい位置をクリック
線の上・線と線の間・五線の外（加線域）も 0.5 行刻みでスナップ
クリックした小節の見た目の横位置に応じて、最も自然な箇所へ 挿入 されます
小節が拍数オーバーになる配置は無視されます（4/4 の範囲チェック）
ヒント：線上に置きたいのに間に吸われる場合は、下の「クリック精度のチューニング」をご覧ください。
🧠 このMVPのコア実装（ざっくり解説）
1) クリック座標と描画座標の基準を統一
クリックは画面のクライアント座標、VexFlow は <svg> 内の <g> ユーザー座標
getScreenCTM().inverse() を使い、client → <g> ユーザー座標に正確変換
クリック用の透明 <rect> も 同じ <g> に追加し、座標系を完全一致
2) Y方向スナップ（音高決定）
stave.getSpacingBetweenLines() を基準に、0.5 行刻みでスナップ
線バイアス：線の中心付近は優先的に線へ吸着（置きやすさUP）
3) X方向の挿入位置
各音符の getAbsoluteX() と 幅（BoundingBox） を使って
クリックXに最も近いスキマ（左/右/中央）へ挿入
連桁や旗などで見た目が詰まっていても、直感どおりの場所に入る
4) 小節幅の自動割り付け
音価ごとに占有感の重みを設定（例：全=1.45／二分=1.25／四分=1.0／八分=0.6／32分=2.2…）
行の空きに応じて比率配分、ただし全・二分を含む小節は下限幅を広めに確保
16分×3＋二分などでも溢れにくい割り付け
🔧 クリック精度のチューニング（線に置きやすくする）
ファイル：src/components/StaffCanvas.tsx
以下の2定数で、**「線に吸着しやすさ」**を調整できます。
// 線の“確定ゾーン”：線の中心 ± (spacing * LINE_PAD_RATIO) に入れば即スナップで線確定
const LINE_PAD_RATIO = 0.18; // 推奨: 0.15〜0.25（値を大きくすると線に置きやすくなる）

// 距離スコアのバイアス：線候補は距離×LINE_BIASとして優遇（1未満で線が有利）
const LINE_BIAS = 0.82; // 推奨: 0.7〜0.9（値を小さくすると線に吸着しやすい）
線に置きづらい → LINE_PAD_RATIO を上げる（例 0.22）、または LINE_BIAS を下げる（例 0.78）
間に置きたいのに線に吸われる → LINE_PAD_RATIO を下げる、または LINE_BIAS を 0.9 近くへ

🧩 よくある質問（FAQ）
Q. クリックが微妙にズレるときは？
A. ブラウザの拡大縮小・CSS transform でも CTM 変換で吸収しますが、環境依存で差が出る場合は LINE_PAD_RATIO を +0.02 ずつ上げてみてください。
Q. クリック領域が狭い？
A. StaffCanvas.tsx 内で getYForLine(-1)〜(5) をヒット領域にしています。さらに広げたい場合はこの範囲を調整してください。
Q. 小節の幅が狭すぎ/広すぎる？
A. UNIT_BY_DENOM（音価の重み）と MIN_MEASURE_W / LONG_HALF_MIN / LONG_WHOLE_MIN を調整してください。
