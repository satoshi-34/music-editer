# Music Editor MVP

Finale ライクな楽譜作成 Web アプリの最小構成（MVP）です。  
React + TypeScript + Vite + VexFlow を使って、**クリックで五線譜に音符を配置**し、**リアルタイムで音を再生**できます。  
MuseScore 風の **小節幅の自動割り付け** と、**クリック位置の高精度スナップ**（線に置きやすいバイアス付き）を実装しています。

---

## 🎵 主要機能

### 楽譜編集
- React + TypeScript + Vite による高速な開発体験
- **単旋律（ト音記号）**・**ピアノ大譜表（右手＋左手）**・**弦楽四重奏（Vn.I / Vn.II / Va. / Vc.）**・**編成譜** の切り替えに対応
- **編成テンプレート**: 弦楽合奏、室内オーケストラ、二管編成オーケストラ、大編成オーケストラ、吹奏楽などを選択可能
- **カスタム編成編集**: 編成譜ではパート名、略称、音部記号を編集し、パートの追加・削除・並び替えができる
- **タブ式ツールバー**: `音符・記号 / 楽譜設定 / 再生・音色 / その他` を切り替えて表示し、ボタン増加時もヘッダーをコンパクトに維持
- **アルト記号（ハ音記号）** に対応（Viola パートで使用）
- **和音入力**: 音符の上をクリックするだけで音を追加（単音→和音。矢印キーで全音を同時移動）
- **休符編集入力**: 音符ツールで休符をクリックすると、同音価ならそのまま置換し、より短い音価なら休符を分割して音符を差し込める（例: 16分休符 → 16分音符、8分休符 → 16分休符 + 16分音符）
- **既定休符位置の調整**: 新しく置いた休符や空小節の見た目用休符は、デフォルトで五線の下から2本目の線にそろえて表示
  デモ譜面内の既存休符データも同じ既定位置へそろえてあるため、サンプル読込時の見た目も一致
- **ピアノ譜 2 voice 基盤**: `MeasureData.voices` を使って、同じ小節内の上声 / 下声を別符幹で持てる土台を追加
- **拍子記号対応**: 譜面ごとに `4/4 / 3/4 / 3/8 / 6/8 / 2/2` を選択でき、表示・入力制限・再生時間計算へ反映
- **臨時記号対応**: パレットの `♯ / ♭ / ♮` ボタンを選んで音符へ適用。`Alt + ↑/↓` の半音移動も継続対応
- **強弱記号対応**: `pp / p / mp / mf / f / ff / cresc. / dim.` を音符へ付与。表示と再生ベロシティを連動
- **調号対応**: `調号` セレクトで基本の調号ファミリーを選択。新規入力や通常の上下移動に既定の `♯ / ♭` を反映
- **タイ／スラー入力**: パレットのタイボタンを選択し、開始音符から終了音符へドラッグして設置。同音はタイ、異音はスラーとして自動判定。小節またぎ・段またぎにも対応
- **リピート記号入力**: パレットの `||:` / `:||` を選び、対象小節をクリックして開始/終了リピートを配置
- **1番括弧 / 2番括弧入力**: パレットの `1.` / `2.` を選び、対象小節をクリックして終止括弧の所属番号を付与
- **弧の選択と編集**: 描画済みの弧をクリックすると青くハイライト。弧をドラッグすると曲率を調節。青いハンドルをドラッグすると接続位置を2D調節。段またぎでは切れ目位置も調節可能。音符の反対側までドラッグすると弧の向きが反転。Delete キーで弧のみ削除（音符は残る）
- クリックで音符／休符を配置（加線域も含め 0.5 行刻みでスナップ）
- 小節幅の自動割り付け（全・二分はやや広め。細かい音符は過密回避）
- 見た目の横位置に最も近い場所へ自然に挿入（getAbsoluteX + BoundingBox）
- 全音価対応（全音符・二分音符・四分音符・八分音符・十六分音符・三十二分音符・六十四分音符）

### 🎶 音符再生機能（NEW!）
- **個別音符再生**: 音符をクリックして即座に音を確認
- **多段譜でも個別再生**: 単旋律だけでなく、ピアノ譜・弦楽四重奏譜でもクリックした音符をその場で確認可能
- **入力確認音の音源統一**: 音符を置いた瞬間の確認音も、再生ボタンや音色プレビューと同じ再生エンジンを使う
- **譜面全体再生**: 再生ボタンで譜面全体を順次再生
- **正確な音高再生**: 五線上の位置に応じた正確な音高
- **音価対応**: 全音符から六十四分音符まで正確な長さで再生
- **テンポ調整**: BPM設定による再生速度制御
- **音色プレビュー**: スピーカーボタンで音色確認
- **フルオケ向け楽器追加**: 木管・金管・弦・打楽器を含む大きめの楽器一覧を選択可能
- **音色詳細UI**: 明るさ、アタック感、余韻、厚みをエンドユーザーが調整可能
- **音源方式切り替え**: 内蔵音源 / SoundFont / プラグイン連携（将来拡張）を選択可能
- **再生フォールバック**: SoundFont の読み込みに失敗した場合は、その再生操作だけ内蔵音源へ退避して無音のまま止まるのを避ける
- **実再生方式の表示**: SoundFont から一時的に内蔵音源へ退避したときは、設定保存値とは別に「今鳴っている方式」を UI に表示して見た目と実音のずれを減らす
- **再生復旧の安全策**: 優先エンジンで再生に失敗した場合は、新しい内蔵音源へ一度だけ退避して再試行し、再生ボタンと音色プレビューが同時に無音になるケースを減らす
- **Safari 安全策**: Safari でもまず選択中の音源方式で再生を試し、初期化や読み込みに失敗したときだけ一時的に内蔵音源へフォールバックする
- **Safari 再利用安定化**: built-in 再生時は毎回 `AudioContext` を捨てず、通常は既存エンジンを再利用して Safari の断続的な無音化を減らす
- **手動の音声復旧**: Safari で silent failure が起きたときは `音声復旧` ボタンで `AudioContext` を作り直し、Safari の再起動なしで戻せる可能性を上げる
- **ブラウザ対応**: 自動再生ポリシーに完全対応

### データ管理
- **保存・読み込み**: LocalStorageによる譜面データの永続化
- **印刷対応**: ブラウザの印刷機能で楽譜を印刷

### Safari 座標補正
- **Y補正ボタン**: Safari で音符配置位置がカーソルとずれる場合に手動で補正
- **操作**: ↑/↓ボタンまたはキーボード矢印キーで調整（低音方向=プラス）
- **保存**: 設定はLocalStorageに保存、次回起動時も維持

### Safari 音声メモ
- **症状**: Safari だけ `音符再生開始` まで進むのに無音になることがある
- **主な要因**: 別タブの動画再生、ホットリロード、タブ復帰後の `AudioContext` の不安定さ
- **参照先**: `docs/audio-safari-notes.md`

## セットアップと起動

### 🐳 Docker（推奨）
```bash
git clone https://github.com/satoshi-34/music-editer.git
cd music-editer
docker compose up
```

### Docker で安全に依存を追加する

`postinstall` 付きのライブラリや、初回は安全側で追加したい依存は、まずコンテナ内で `--ignore-scripts` を付けて入れます。  
このリポジトリでは、初心者でも手順を間違えにくいように補助スクリプトを用意しています。

```bash
sh ./scripts/safe-add-package-in-docker.sh soundfont-player
```

`npm run` 経由で実行したい場合は次でも同じです。

```bash
npm run deps:add:safe -- soundfont-player
```

- Docker Desktop が起動していれば、コンテナ内で `npm install --ignore-scripts` を実行します
- `package.json` と `package-lock.json` はホスト側にも反映されます
- `node_modules` は Docker volume 側を使うため、ローカル環境を汚しにくいです
- 追加後に本当に script 実行が必要かを確認してから、通常インストールや個別コマンドを検討します

## 使い方

Git の作業ルールは [GIT_RULES.md](/app/GIT_RULES.md) にまとめています。

### 基本操作
1. **スコアタイプ選択**: ツールバーで「単旋律」「ピアノ」「弦楽四重奏」「編成譜」を選択します
2. **音価選択**: 画面上の Palette で音価（全音符・二分音符・四分音符・八分音符など）や休符を選びます
3. **音符配置**: 五線譜の置きたい位置をクリックします。線／間／五線の外（加線域）も 0.5 行刻みでスナップします
4. **拍数制限**: 選択中の拍子で許される小節長を超える配置は無視されます
5. **休符の編集**: たとえば 16分音符ツールで 16分休符をクリックするとそのまま 16分音符へ置き換わり、8分休符の右半分をクリックすると `16分休符 + 16分音符` に分割できます

### 弦楽四重奏
- 「弦楽四重奏」ボタンを選択すると Vn. I / Vn. II / Va. / Vc. の 4 段譜面が表示されます
- Viola 段はアルト記号（ハ音記号）が表示され、中央線が C4 になります
- 各段独立して音符を配置でき、再生ボタンで 4 パート同時に再生されます

### 編成譜
- 「編成譜」を選ぶと、編成テンプレートに沿った複数パート譜が表示されます
- 「編成」セレクトで室内オーケストラ、二管編成オーケストラ、吹奏楽などを切り替えられます
- パート編集では、パート名、略称、音部記号を変更できます
- 「追加」「削除」「↑」「↓」でパート数と並び順を変更できます
- プリセットを編集すると `カスタム編成` として保存されます

### 和音入力
- **基本操作**: まず通常クリックで音符を配置し、その後 **同じ音符の上をクリック**（Y 位置が和音ゾーン内）で音を追加。Shift キーは不要
- **和音ゾーン**: 音符の描画 X 範囲（± CHORD_HIT_PAD）かつ五線 ± 3加線の固定 Y 範囲内がゾーン。ゾーン外のクリックは新規音符挿入になる
- **音の移動**: 矢印キー（↑/↓）で和音を構成するすべての音を同時にシフト（`Alt` で半音、`Shift` でオクターブ）
- **同時再生**: PolySynth が和音を1コールで同時発音。スコア再生時も全音が正確に再生される

### 臨時記号
- **パレット操作**: `♯ / ♭ / ♮` ボタンを選んだあと、対象の音符セルをクリックすると臨時記号を適用します
- **背景クリックでは挿入しない**: `♯ / ♭ / ♮` ツール中に小節背景をクリックしても、新しい音符は置かれません
- **和音への適用**: 和音をクリックした場合は、そのイベントに含まれる音すべてへ同じ臨時記号を適用します
- **半音入力**: キーボード派向けに `Alt + ↑/↓` の半音移動も引き続き使えます
- **ナチュラル表示**: 同じ小節内で先に変化していた同音名・同オクターブの音を自然音へ戻すと、ナチュラル記号（`n`）を自動表示します
- **重複抑制**: 同じ小節内で同じ臨時記号状態が続く場合、不要な `#` / `b` の重複表示を省きます
- **確認音の切替**: 音色詳細内のチェックボックスで、臨時記号を付けた直後の確認音を ON/OFF できます

### 強弱記号
- **パレット操作**: `pp / p / mp / mf / f / ff / cresc. / dim.` ボタンを選び、対象の音符セルをクリックします
- **解除方法**: 同じ強弱ボタンを選んだまま同じ音符をもう一度クリックすると、その種類の記号を外せます
- **共存ルール**: 絶対強弱（`p` など）と変化強弱（`cresc.` / `dim.`）は同じ音符に併記できます
- **再生反映**: 再生ボタンの譜面全体再生では強弱記号をベロシティへ変換し、`cresc.` / `dim.` は次の絶対強弱へ向かって段階的に増減します

### リピート記号
- **パレット操作**: `||:` で開始リピート、`:||` で終了リピートを選びます
- **配置方法**: 記号を置きたい小節の背景または音符セルをクリックすると、その小節線にリピート記号が付きます
- **解除方法**: 同じ記号ツールを選んだまま、同じ小節をもう一度クリックすると外せます
- **両方配置**: 同じ小節に `||:` と `:||` を別々に付けることもできます
- **再生反映**: `||:` から `:||` までは、譜面再生時に 1 回だけ折り返して再生します
- **開始記号省略**: `:||` だけ置いた場合は、譜面の先頭からその小節までを折り返します

### 調号
- **調号選択**: ツールバーの `調号` セレクトで、調号なし / ♯系 / ♭系の調号ファミリーを選べます
- **行頭クリックでも変更**: `♯ / ♭ / ♮` ツールを選んで各段の行頭をクリックすると、調号を1段ずつ増減できます。`♮` は調号なしへ戻します
  拍子記号がある段では、その右側から音符の手前までを調号クリック領域として扱います
  `♯ / ♭ / ♮` ツール中は、調号クリック領域を薄いオレンジ色で表示し、クリック時にブラウザコンソールへ診断ログを出します
  既存の音符セルを押したときは常に臨時記号、音符の無い小節背景の調号領域を押したときだけ調号として扱います
  `♯` はシャープ系の調号を、`♭` はフラット系の調号を増やしていき、別系統へ切り替えるときはまず `♯1つ` / `♭1つ` から始めます
  初期表示の全休符は見た目だけのガイドとして描画し、巨大な編集ヒット領域は持たせません
- **表示位置**: このエディタでは先頭行の調号を拍子記号の右側へ表示します
- **入力への反映**: 調号に含まれる音は、新規入力や通常の上下移動で既定の `f#` や `bb` を自動反映します
- **表示の省略**: たとえば G 系（♯1つ）で `f#/4` を置いた場合、臨時記号は毎回は出ず、調号に含まれる音として扱います
- **ナチュラル表示**: 調号で `F#` が既定のときに `f/4` を置くと、必要な位置にだけナチュラルが表示されます

### 🎵 音符再生
1. **個別再生**: 配置した音符をクリックして音を確認
   個別再生も、再生ボタンやプレビューで選んだ現在の楽器音色に追従します
2. **全体再生**: ツールバーの再生ボタン（▶️）で譜面全体を再生
3. **音色確認**: スピーカーボタン（🔊）で現在の音色をプレビュー
4. **音源方式切り替え**: 必要に応じて `内蔵音源` と `SoundFont` を切り替える
5. **テンポ調整**: BPM設定で再生速度を変更

### データ管理
1. **保存**: 「保存」ボタンで譜面をLocalStorageに保存
2. **読み込み**: 「読み込み」ボタンで保存した譜面を復元
3. **サンプル**: 「サンプル譜の種類」を選んで、説明用デモ譜や音色確認用フレーズを表示
4. **印刷**: 「印刷」ボタンでブラウザの印刷ダイアログを開く

### Safari でのY補正
1. ツールバーの **「Y補正」** ボタンをクリック
2. ↑（高音方向）/ ↓（低音方向）ボタン、またはキーボード ↑↓ キーで値を調整
3. ガイドラインと音符配置が一致したら完了（設定は自動保存）

## 実装のポイント（要点）

### 1. クリック座標と描画座標の基準を統一（Safari 対応済み）
- クリックはクライアント座標、VexFlow は SVG viewBox 座標です。
- `getAccumulatedCSSZoom()`（HTML 要素 `.page-wrapper` から `--scale` を読取）+ viewBox 比率変換で **client → SVG viewBox 座標**へ変換。
- CSS `zoom` プロパティに対し、Safari（論理サイズを返す）と Chrome（視覚サイズを返す）を動的に判別して補正。
- 自動補正で解消しない場合はツールバーの **「Y補正」** で手動キャリブレーション可能（設定 localStorage 保存）。

### 2. Y 方向スナップ（音高決定）
- `stave.getSpacingBetweenLines()` を基準に **0.5 行刻み**でスナップ。
- 線に置きやすいよう **線バイアス**（`LINE_PAD_RATIO`, `LINE_BIAS`）を適用。

### 3. X 方向の挿入位置
- 各音符の `getAbsoluteX()` と幅（BoundingBox）を使い、クリック X に最も近い隙間へ挿入。

### 4. 小節幅の自動割り付け
- 音価の「占有感」に重みを持たせて比例配分。全・二分を含む小節は下限幅を広めに確保。
- 16 分や 32 分が並んでも符頭が重なりにくいようチューニング。

### 5. 🎵 音符再生システム
- **SimpleAudioEngine**: Web Audio APIを直接使用した軽量な音声エンジン
- **SoundFontEngine**: 既存の楽器サンプルを読み込み、より楽器らしい音で再生するエンジン
- **音色確認用サンプル**: ピアノ説明用、金管テスト、弦テストを切り替えて聴き比べできる
- **ピアノサンプルの更新**: 固有曲名ベースのサンプルではなく、`3/8`・休符・リピート・終止括弧・強弱をまとめて確認しやすいピアノ用デモフレーズへ差し替えた
- **複数声部の基盤**: ピアノ譜では 2 voice を保持できるデータ構造を用意している。現在のデモフレーズは、機能確認を優先して単声部寄りに整理している
- **簡易音色プリセット**: ピアノ、ギター、木管群、金管群、弦群、打楽器群を含むフルオケ寄りの楽器一覧を切り替え可能
- **音色詳細UI**: 明るさ / アタック感 / 余韻 / 厚みをスライダーで調整可能
- **音源方式**: `内蔵音源 / SoundFont / プラグイン連携` を切り替えられる
- **SoundFont 実装**: 既定では `FluidR3_GM` を選択し、必要に応じて `MusyngKite` など別パック名へ切り替えられる
- **フォールバック表示**: SoundFont 失敗時は保存設定を残したまま、再生パネル上では一時的に `内蔵音源` 表示へ切り替えて現在の実動作を伝える
- **音高変換**: Vexflow形式（`c/4`）からMIDI形式（`C4`）への自動変換
- **調号つき入力**: 調号に含まれる線・間へ通常入力した場合は、内部キー文字列も `f#/4` や `bb/3` に補正して再生音と表示を一致させる
- **音価計算**: BPMに基づく正確な再生時間計算
- **ブラウザ対応**: 自動再生ポリシーに完全対応（ユーザーインタラクション後に初期化）
- **Safari対策**: `running` に見えても無音になるケース向けに、出力経路ウォームアップと失敗時のみの一時的な内蔵音源フォールバックを実装
- **再生成の抑制**: `ScorePage` では built-in の通常再生で毎回エンジンを捨てず、`AudioContext` の作り直しは方式切替・背景復帰・実失敗時に限定して Safari の不安定さを避ける
- **強めの音声復旧**: `音声復旧` は無音時に `built-in + ピアノ + 既定プロファイル` へ安全に戻して、壊れた保存設定を持ち越さないようにする
- **最小テスト音**: 再生エンジンを通さない純粋な Web Audio の確認音を鳴らし、ブラウザ出力とアプリ経路の切り分けに使える
- **設定読込の安全化**: localStorage の再生設定は型と値域を検証し、不正値は既定値へ戻す
- **リピート記号の保存**: 開始/終了リピートは `MeasureData` の小節属性として保存し、音符編集時も落とさない共通複製関数で守る
- **リピート再生順の展開**: `ScorePage` は再生前に小節順を安全に展開してから各音源へ渡し、各 `:||` で 1 回だけ折り返す。想定外データでは安全上限で打ち切って無限ループを防ぐ
- **1番括弧 / 2番括弧の再生分岐**: `MeasureData.ending` をもとに、1周目は 1番括弧、2周目は 2番括弧だけを鳴らす基本分岐へ対応
- **サンプル譜での記号体験**: ピアノ用デモフレーズにはリピート、1番括弧 / 2番括弧、強弱記号を実際に入れてあり、見た目と再生の両方で確認できる
- **再生位置の視覚化**: 再生ボタンの進行に合わせて現在の音符を青くハイライトし、スクロール外に出たときは自動追従する
- **拍子の保存と復元**: localStorage には score ごとの `timeSignature` も保存し、読み込み時は無効値を安全な 4/4 へ戻す
- **拍子ごとの入力上限**: `StaffCanvas / PianoSystemCanvas` は `3/8` なら 1.5 拍まで、`6/8` なら 3 拍まで、という形で小節長を判定する
- **終止括弧の描画**: 終止括弧の保存データは小節番号だけにとどめ、描画時に前後小節を見て `BEGIN / MID / END / BEGIN_END` を自動決定する
- **現状のサンプル制限**: ピアノ用デモフレーズは編集・再生の確認を優先した短い説明用データであり、独立テキスト記号や曲全体の完全採譜までは含めていない
- **固定ヘッダーの高さ自動計測**: タブ切り替えでツールバーの高さが変わっても、本文が下へ潜り込まないよう `ResizeObserver` で余白を同期する
- **強弱の保存検証**: `dynamics.value` は許可済み文字列だけを localStorage から受け入れ、未知の値が描画や再生へ流れないようにする
- **強弱の再生解決**: `dynamicMarkingUtils.ts` で絶対強弱と `cresc.` / `dim.` の段階変化を共通計算し、`ScorePage -> PlaybackEngine.playParts()` の現在経路でも譜面再生音量へ反映する
- **編成データの保存**: `SavedScoreData.instrumentation` に編成テンプレートとパート定義を保存し、旧データでは省略可能として後方互換を保つ
- **可変編成の描画**: `ScorePage` で `ensemble` モードを持ち、`EnsembleStaff` から既存の N 段対応 `PianoSystemCanvas` へパート配列を渡す
- **カスタム編成の同期**: パート追加・削除・並び替え時は、編成定義と実際の小節データ配列を同じ順序で更新し、表示と保存のずれを防ぐ

### 6. 和音（複数音符の同時配置・再生）
- `NoteEvent.keys: string[]` が単音・和音の両方を表現（単音も長さ1の配列）。v2→v3マイグレーションで旧データを自動変換。
- 音符の上をクリックすると和音追加になる。Shift キー不要。追加後は `keyToLine` で昇順ソートし、VexFlow が期待する「低音から高音」の配列順を維持。
- **和音ゾーン判定**: X方向は `getBoundingBox()` で取得した実際の符頭描画範囲（± CHORD_HIT_PAD px）。Y方向は五線 ± 3加線の固定範囲（`getYForLine(-3)` 〜 `getYForLine(7)`）。ゾーン外のクリックは新規音符挿入になる。
- `vf-note-hit` rect を和音ゾーン全体の高さに設定することで、加線域へのクリックも正しく捕捉する。
- キーボードハンドラは `ev.keys.map(k => ...)` で全音を均等にシフト（音程を保ったまま移動）。
- PolySynth の `triggerAttackRelease(noteArray, ...)` が和音を1回の呼び出しで同時発音。`ScorePlayer` も `note: string[]` を保持し、スコア再生でも和音が鳴る。

### 7. 臨時記号（シャープ・フラット・ナチュラル）
- 音高データは既存どおり `keys` に保存し、`f#/4` や `bb/3` のように表現する。
- 描画時は小節ごとに `Map<音名/オクターブ, 現在有効な臨時記号>` を持ち、必要な位置にだけ `# / b / n` を付ける。
- 同じ小節内で同じ状態が続く場合は記号を省略し、変化した音を自然音へ戻したときだけ `n` を表示する。
- 保存時は `src/utils/storage.ts` で音高キー文字列を検証し、未知の文字列が描画系へ流れ込まないようにしている。

### 8. タイ／スラー（TieArc）入力と編集

#### データモデル
- `NoteEvent.arcs?: TieArc[]` に弧情報を保存。`fromKey`/`toKey` で和音内の個別符頭を指定。`kind: 'tie' | 'slur'` で種別を区別。
- 調節量は `cpDyOffset`（曲率）、`startDx/Dy`・`endDx/Dy`（始終点オフセット）、`flipDirection`（向き反転）として保存。すべて optional なので既存データに影響なし。

#### 描画（`arcUtils.ts` / `drawArcPath`）
- タイは二次ベジェ Q、スラーは常に三次ベジェ C で描画（`computeArcGeometry`）。
- 各弧を透明な幅広ヒットパス（`stroke-width:10`）＋可視パス（`stroke-width:1.5`）の2枚重ねで描画。選択中は青（`#3b82f6`）に変色。
- 段またぎ弧は `-1`（開始音符→段末端）と `-2`（次段先頭→終了音符）に分割して描画。

#### インタラクション
- **弧ドラッグ（曲率調節）**: hitPath の mousedown で cpDrag 開始。mousemove で DOM を直接更新（再レンダなし）。mouseup で `cpDyOffset` を保存。
- **向き自動反転**: 曲率ドラッグ中にカーソルが音符クラスタを 20px 超えると `flipDirection` が自動トグル。
- **始終点ドラッグ**: 選択中の弧に青い丸ハンドルを表示。ドラッグで `startDx/Dy` または `endDx/Dy` を調節。
- **Delete キー優先順位**: スラー選択中は Delete で弧のみ削除（音符は残る）。音符選択中は従来通り音符を削除。

#### arcGeomMap
各弧の形状パラメータ（座標・向き・ep オフセット・cpDyOffset）を `useEffect` 内で保持。ライブドラッグ時の再計算に使用し、React 再レンダを経由しないで応答速度を確保する。

### 9. N 段譜表の汎用レンダリング（弦楽四重奏対応）
- `PianoSystemCanvas` を `partsConfig: PartConfig[]` prop で N 段対応に一般化。
- `computeLayout(n)` が段数に応じて `staveYs`・`sysH` を動的に算出（`STAVE_SPACING=80px`）。ピアノ（N=2）は従来値と完全一致。
- `StaveConnector` を N=2 で BRACE（ピアノ）、N>2 で BRACKET（オーケストラ）に自動切替。
- **アルト記号（ハ音記号）**: `clefUtils.ts` の `lineToKey('alto', line)` が `G4=line0, C4=line2` を基準に音高を計算。VexFlow 5 はネイティブで `'alto'` 文字列に対応。

## クリック精度のチューニング

`src/components/StaffCanvas.tsx` の定数で調整できます。

```ts
// 線の中心 ± (spacing * LINE_PAD_RATIO) に入れば即スナップで線確定
const LINE_PAD_RATIO = 0.18; // 例: 0.15〜0.25

// 線候補の距離スコアに掛ける係数（1 未満で線を優遇）
const LINE_BIAS = 0.82; // 例: 0.7〜0.9
```
- 線に置きづらい → `LINE_PAD_RATIO` を上げる、または `LINE_BIAS` を下げる
- 間に置きたいのに線に吸われる → `LINE_PAD_RATIO` を下げる、または `LINE_BIAS` を上げる

## 最小チェック

### 楽譜編集
- scale=1.0 / 0.86 / 0.8 で E4→G4→B4→D5（ミ・ソ・シ・レ）が狙い通り置ける
- 線の上クリックでも間に吸われない
- 16 分×3 + 二分 などでも小節から溢れない
- 休符は 1 回目のクリックで選択でき、Delete で削除できること
- 新しく置いた休符と空小節の休符は、初期状態で五線の下から 2 本目の線に見えること
- 選択した休符は ↑/↓ で高さを動かせること
- 音符ツール時は、同じ休符をもう一度クリックすると置換・分割入力できること
- ピアノ譜の再生では、3/8 のような拍子でも左右手が同じ小節長でそろうこと
- ピアノ譜のリピート記号と 1番/2番括弧は、片手だけに入っていても全段が同じ順番で再生されること
- ピアノ譜では、現在の編集中譜面を「いまの譜面」サンプルとして保存し、あとでサンプル欄から再読込できること
- 拍子記号はいまの仕様では譜面全体のいちばん最初だけに表示されること
- 音符を新規配置したときや、休符を音符へ置換・分割したときに確認音が鳴ること
- 音符を新規配置した瞬間の確認音も、再生パネルで現在選んだ楽器音色に追従すること

### 🎵 音符再生
- 異なる高さの音符で音高が変わることを確認
- 異なる音価で再生時間が変わることを確認
- 再生ボタンで譜面全体が順次再生されることを確認
- 音符クリックで個別再生されることを確認

### 和音
- 音符を配置後、同じ音符の上（和音ゾーン内）をクリックすると和音に追加されること（Shift 不要）
- ゾーン外（セル内の空白部分）をクリックすると新規音符が挿入されること
- 矢印キーで和音全体が移動し、音程が保たれること
- 和音クリック時に全音が同時に鳴ること
- 保存 → 読み込みで和音データが正しく復元されること（旧データの単音も自動変換）

### タイ／スラー
- タイモードで同音をドラッグ → タイ（同じ音高間の黒い弧）が描画されること
- タイモードで異音をドラッグ → スラー（異なる音高間の弧）が描画されること
- 弧をクリックすると青くハイライトされ、始終点に青いハンドルが表示されること
- 弧をドラッグすると形状（曲率）がリアルタイムで変わり、離すと保持されること
- 始点または終点ハンドルをドラッグすると接続位置が移動すること
- 段またぎ弧では切れ目の上下ハンドルをドラッグして分割位置を調節できること
- 弧を大きく音符の反対側へ引っ張ると弧の向きが反転すること
- Delete キーで選択中の弧のみが消え、音符は残ること
- Escape で弧の選択が解除されること
- 保存 → 読み込みでタイ／スラーと全調節量が正しく復元されること

### 弦楽四重奏
- 「弦楽四重奏」ボタンで 4 段譜面が表示されること
- Viola 段にアルト記号が表示され、中央線が C4 になること
- Vn. I / Vn. II / Va. / Vc. それぞれ独立して音符を配置できること
- 角括弧（BRACKET）が 4 段全体に表示されること
- 全体再生で 4 パート同時に音が出ること
- 保存 → 読み込みで各パートが正しく復元されること
- ピアノモードに切り替えても BRACE とレイアウトが崩れないこと
