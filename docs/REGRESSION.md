# Regression Checklist (quick)

## A. クリック精度
- [ ] scale=1.0 / 0.86 / 0.8 で、1段目の1小節目に **E4, G4, B4, D5**（=ミ・ソ・シ・レ）を下からクリックして狙い通りに入る
- [ ] 五線の「線の上」をクリックしても上の間に吸われない（線に吸着）
- [ ] 五線の外（加線域：line=4.5 以降）でも正しい音高が入る

## D. Safari 固有チェック（再発防止）
> CSS `zoom` プロパティ起因の座標ズレバグが過去に繰り返し発生。
> 2026-06 にページ縮小を `transform: scale` へ置き換えて根本対策済み（issue #13）だが、**Safari での確認は継続すること。**
> あわせて `.page-wrapper` / `.print-page` へ CSS `zoom` が再導入されていないことも確認する。
- [ ] **Safari** で scale=1.0 のとき、ガイドライン（ホバー時の横線）がマウスカーソルと同じ高さに表示される
- [ ] **Safari** で scale=0.86 / 0.8 のとき、ガイドラインがマウスカーソルと同じ高さに表示される
- [ ] **Safari** でクリックした位置と音符が描画される高さが一致する（ガイドラインの高さ＝実際の音符の高さ）
- [ ] **Chrome** で同じ操作を行い、Safari との表示差がないことを確認する
- [ ] ページ縮小時（scale<1.0）に、ページ間の余白が間延びしていない（`ScaledPageWrapper` の高さ補正が効いている）
- [ ] 印刷プレビューでページが原寸（縮小されていない状態）で出力される

**上記が失敗した場合は [`docs/safari-coordinate-transform.md`](safari-coordinate-transform.md) を参照。**

> 手動の逃げ道だった「Y補正」ボタンは Issue #134 で撤去済み（対症療法UIのため）。ここが失敗したら座標変換そのものの退行を疑い、対症療法で埋めずに原因を直すこと。

## E. Safari 音声チェック（再発防止）
> Safari では `AudioContext` が `running` に見えても、別タブの動画再生やホットリロード後に無音になることがある。
- [ ] **Safari** で音色プレビューが鳴る
- [ ] **Safari** で譜面再生が鳴る
- [ ] 別タブで動画や音声を再生したあとでも、Safari 側に戻って再生できる
- [ ] コンソールに `[SimpleAudioEngine] 出力経路をウォームアップしました` が出る
- [ ] **Chrome** では同じ操作で常に鳴る
- [ ] 正常に鳴っているとき、再生ボタン付近に無音検知の通知が**出ない**（誤検知チェック）
- [ ] 再生開始直後（1秒以内）に一時停止しても、無音検知の通知が**出ない**（一時停止の suspended は正常な状態）
- [ ] 無音が発生した場合、コンソールに `[ScorePage] 無音状態を検知しました:` の診断ログが出て、再生ボタン付近に自動再起動の通知が出る（このログを issue #14 へ貼る）

**上記が失敗した場合は [`docs/audio-safari-notes.md`](audio-safari-notes.md) を参照。**

## B. 小節幅の自動割付
- [ ] 「十六分×3＋二分」など細かい音価と長い音価が混在しても溢れない
- [ ] 全音符・二分音符を含む小節が“やや広め”に割り当てられる
- [ ] 32分・64分が続く小節でも符頭が重ならない

## F. アーティキュレーション（奏法記号）
- [ ] パレットの `•` / `>` / `‒` / `^` / `𝄐` を選んで音符をクリックすると記号が付く
- [ ] 同じボタンで同じ音符を再クリックすると外れる（トグル）
- [ ] スタッカート＋アクセントのように複数を重ねて付けられる
- [ ] 休符をクリックしても何も起きない
- [ ] フェルマータ・マルカートは符頭の上に表示される
- [ ] 再生で、スタッカートが付いた音は短く切れ、アクセント／マルカートは強く鳴る（テンポ自体は変わらない）
- [ ] 保存→再読込で記号が保持される

## G. 小節選択（Issue #145）
> 選択ハイライトは `.vf-hit` の `fill: transparent !important` に負けて**一度まったく見えなくなっていた**。
> クラス `vf-measure-selected` で上書きしているので、CSS を触ったら必ず「見えるか」を確認する。
- [ ] 小節選択ツールでクリック → その小節が青枠＋薄青で塗られる（4譜種すべて）
- [ ] 小節Aで押して小節Bまでドラッグ → A〜B がまとめて選択される（音符が詰まった小節を通っても途切れない）
- [ ] ドラッグ範囲選択の直後でも、次の1クリック（または Shift+クリック）が無反応にならない
- [ ] 音符ツール中に小節を `Shift+クリック` → 小節選択になり、音符は置かれない
- [ ] 音符ツール中の通常クリック（Shift なし）は従来どおり音符が置かれる
- [ ] 複数パートの譜面では、選んだ小節位置の全パートが同時に選択される
- [ ] 印刷プレビュー・PDF書出・印刷に選択ハイライトが出ない

## H. 記号の調整オーバーレイ（Issue #230）
> クリック位置にそのまま開いていたため、調整対象の記号を自分で隠していた。
> 配置ロジックは `symbolOverlayPlacementUtils.ts` に集約し、サイズ変更・位置調整で共有している（2系統にしないこと）。
- [ ] 譜面**中央**の記号で位置調整（✥）を開く → オーバーレイが記号を隠さない
- [ ] 譜面**上端**（1段目・ツールバー直下）の記号で開く → 上に入らないので下へ回り、ツールバーの下に潜らない
- [ ] 譜面**下端**の記号で開く → 画面下へはみ出さない
- [ ] 譜面の**左端・右端**の記号で開く → 左右に見切れない
- [ ] 開いたまま矢印キーで動かす → 記号は動くが**オーバーレイは動かない**（記号もオーバーレイも見えたまま）
- [ ] サイズ変更（⤢）でも上の5項目が同じように成り立つ
- [ ] ページを縮小表示（scale<1.0）した状態でも、オーバーレイが記号の近くに出る

## I. 削除のフィードバックと選択の自動解除（Issue #238）
> 選択（青枠）が残ったまま Delete が譜面へ届き、三連符がグループごと**無言で**消える事故が実機で起きた。
> 「確認ダイアログを出さず、起きたことを通知する」「モードが変わったら選択を手放す」の2本立てで対処している。
> 設計の詳細は [`.claude/specs/delete-feedback-and-selection-clear/design.md`](../.claude/specs/delete-feedback-and-selection-clear/design.md)。
- [ ] 音符を選択 → `Delete` → 画面下端の中央に「音符を削除しました（Cmd/Ctrl+Z で元に戻せます）」が数秒出て、自動で消える
- [ ] 3連符の**2音目**（他に音符が残る位置）を選択 → `Delete` → **その位置だけが連符内の休符になり**、連符の囲み・数字・残りの音符はそのまま。「連符内の音符を休符にしました」と出る（Issue #283。声部1・声部2どちらでも同じ）
- [ ] そのまま残りの音符も順に `Delete` → **最後の1音を消したときだけ**グループ全体が同じ長さの通常の休符1つになり、「3連符グループを削除しました」と出る
- [ ] 連符内の**休符**を選択 → `Delete` → 従来どおりグループ全体が通常の休符になる（グループごと消したいときの近道）
- [ ] ピアノ譜の**声部2**で和音の1つの符頭を選択 → `Delete` → **その1音だけ**が消え、「和音の1音を削除しました」と出る（Issue #280。連符の中の和音でも同じで、連符グループ・残りの音・ビームは維持される。声部2の和音の最後の1音を消したときだけ、従来どおりグループごと休符になる）
- [ ] 削除で**確認ダイアログが出ない**（選択→即 Delete の操作感が従来どおり）
- [ ] 音符を選択 → ツールバーのタブを切り替え → 青枠が消える。そのあとの `Delete` で譜面が変わらない
- [ ] 音符を選択 → パレットで別の音価を選ぶ → 青枠が消える
- [ ] 音符を選択 → 再生を開始 → 青枠が消える
- [ ] スラー／松葉を選択した状態でも、上の3つのきっかけで選択が外れる
- [ ] スラー／松葉を選択 → `Cmd/Ctrl+Z` で**その弧が消える** → `Delete` を押しても、残っている別の弧・松葉が消えない（Issue #265。index 参照の残存選択で「選んでいない弧」が消える事故）
- [ ] スラー／松葉を選択 → **別の小節だけ** Undo → `Delete` で、選んでいた弧はちゃんと消える（安全解除が効きすぎて毎回選び直しにならないこと）
- [ ] 通知が出ているあいだも、その真下あたりの譜面をクリックできる（通知がクリックを吸わない）
- [ ] 保存の状態表示（画面右下）と削除の通知（下端中央）が同時に出ても重ならない

## J. 再生中の位置ハイライト（Issue #268）
> 再生位置は「符頭の色を青く変える」方式から「段の背面に淡い橙色の縦帯を出す」方式へ変えた。
> 旧方式は選択（青枠）と混同するうえ、当たり判定 rect を書き換えるので消し残しが譜面に色として残った。
> 設計の詳細は [`.claude/specs/playback-position-visualization/design.md`](../.claude/specs/playback-position-visualization/design.md)。
- [ ] 再生すると、鳴っている位置に**橙色の縦帯**が出て音符と一緒に進む（青ではない＝選択枠と見分けが付く）
- [ ] 帯は**音符の背面**にあり、符頭・符幹・五線が帯に隠れない
- [ ] ピアノ大譜表・編成譜で、帯が**段の上から下まで**を1本で貫く（片方のパートしか鳴っていない拍でも高さが変わらない）
- [ ] 再生中に譜面をクリックできる（帯がクリックを吸わない）
- [ ] 一時停止・停止・別タブへ切り替えて戻る、のいずれでも帯が消える。**消えたあと譜面に色が残らない**
- [ ] 複数ページの譜面（レイアウトの「段数/ページ」を減らす）でも帯は同時に1本だけ
- [ ] 印刷プレビュー・PDF書出で帯が出ない（黒い矩形にもならない）

## K. 和音の同音重複を作らせない（Issue #281）
> 同じ高さの符頭は完全に重なって1つに見えるため、重複が入ると利用者は気づけず、
> 「1音消したのに見た目が変わらない」という原因の分かりにくい症状になる。
> 設計の詳細は [`.claude/specs/bug-fixes/design.md`](../.claude/specs/bug-fixes/design.md) の Issue #281 の節。
- [ ] 和音の1音を選択 → 矢印キーで既存の音と**同じ高さ**へ動かす → 符頭が1つにまとまり、「和音の1音にまとめました」の通知が出る
- [ ] まとめた直後にもう一度矢印キー → **残った1音だけ**が動く（和音全体が動かない＝選択が付け替わっている）
- [ ] `Cmd/Ctrl+Z` で元の和音（2音）に戻る
- [ ] 重ならない移動では音数が変わらず、通知も出ない
- [ ] 和音**全体**を選択した状態の矢印キー移動は従来どおり（音数が変わらない）
- [ ] `docs/qa/regression/moonlight-bars1-9.score.json` を「ファイルを開く」で読み込む → 3小節目右手と8小節目の声部2にあるユニゾン重複が1音になっている（他の音高・スラー・連符は不変）

## L. 連符グループの連続性（Issue #282）

> 連符グループは「同じ tuplet.id が**連続**する区間」として扱われる。
> 挿入位置がグループの内側に入るとグループが前後に割れ、囲み（「3」と括弧）が消える・
> 削除やコピーが断片しか掴めない、という壊れ方をする。
> 設計の詳細は [`.claude/specs/tuplet-implementation/design.md`](../.claude/specs/tuplet-implementation/design.md) の追記9。
- [ ] 3連符を1つ置いたあと、その**2音目・3音目の真上あたり**をクリックして音符を置く → 連符の囲みが消えず、新しい音符はグループの外（手前か直後）に入る
- [ ] 同じ操作を**連符ツール**で行う → 新しい連符グループが既存グループの外に3音そろって入る
- [ ] 同じ操作を**声部2**で行っても同じ結果になる
- [ ] 分断された連符を含む古い保存データ（月光 fixture の9小節目）を「ファイルを開く」で読む → 連符の囲みが全グループぶん描かれる
- [ ] 同じデータを localStorage 経由（自動保存の復元）で読んでも同じ結果になる
- [ ] 開発ビルドで編集していて、コンソールに `[storage] 連符グループが分断されたまま保存されようとしています` が出たら、その直前の操作が新たな発生経路（Issue を立てる）

## C. そのほか
- [ ] 1段目（拍子記号あり）／2段目以降（拍子記号なし）で挙動が変わらない
- [ ] 休符を配置しても中央揃えで崩れない
- [ ] 記号のサイズ（⤢）・位置（✥）の入力欄を開いたまま別のツールを押すと入力欄が閉じ、**次の音符クリック1回**で新しいツールのオーバーレイが開く（Issue #231。**Safari で必ず確認**すること。Chrome 系はボタンのクリックでフォーカスが移るため入力欄が自動で閉じてしまい、症状が出ない）
- [ ] 同上の切り替えは Esc と同じ扱い＝矢印キーで動かした未確定ぶんは保存されず、「元に戻す」が有効化しない
