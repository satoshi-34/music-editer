ベートーヴェン「月光ソナタ」第1楽章の1〜9小節。**2026-08-11 の運用者による実機テストで実際に入力された譜面**をそのまま保存したもの（SHA-256: 1beb6b3d246a13d24c8b1f5ddf8cd37ea37a29e3af5d77811c6ed3c94bfc5d8b）。

### なぜこのファイルが正本級に重要か

この1ファイルに、アプリの主要機能がほぼ全部詰まっている:

- 三連符（連続グループ・連符IDの独立性）
- 小節ごとの2声部（右手: 旋律＋三連符 / 左手: 和音＋オクターブ、`stemDirection` 付き）
- 小節をまたぐスラー（7→8小節、制御点オフセット付き）・小節内スラー
- 付点リズム・明示的な休符（2分+4分）・和音
- テンポ表記「Adagio sostenuto」・発想標語（Si deve suonare...）・強弱 pp・運指（サイズ/位置の個別調整付き）
- 段あたり小節数のオーバーライド（3小節×3段）

このファイルが**読み込めて・描けて・鳴らせる**ことが、リリース前の最低ラインである。

### 既知の入力上の傷（バグ再現データとして意図的に残す）

1. **5小節目・右手声部2の最初の三連符が b/1, d#/2, g#/2**（本来 g#/3, c#/4, e/4）。#219 の誤帰属で入った超低音で、#218 修正前は選択不能だった実物。修正後の「救出できること」の検証データを兼ねる
2. **8小節目・右手声部2に b/3 の3重ユニゾン和音**（誤クリックの実物）
3. **9小節目・右手声部2の連符IDが交錯**（イベント順とグループIDの対応が入れ子）

これらを「直した版」を作る場合は別ファイル（-clean.score.json）とし、本ファイルは書き換えない。
