# 楽譜編集の実機チェックリスト（白紙から）

対象: dev（localhost:5173）。機能が増えたら項目を足す（正本はこのファイル）。**🔇 印は音が出る操作**なので、診療中（マイクON）はやらない。
記録のしかた: できたら ✓、変だったら「NG＋一言」。NG はこちらで Issue にします（出典＝このリスト）。

---

## 0. 白紙から始める
- [ ] ホーム →「ピアノ」で新規作成。大譜表（右手・左手）の空の譜面が出る
- [ ] タイトルをクリックして入力・サブタイトル/作曲者も入る（書体・サイズ・太さは楽譜設定タブ）
- [ ] 楽譜設定タブ: 拍子 3/4 → 4/4 に戻す、調号を E 長調にする（♯4つが両段に出る）
- [ ] 「元に戻す」で調号が戻る／「やり直す」で戻る

## 1. 音符を置く（音符・休符タブ）
- [ ] 4分音符を選んで右手の五線をクリック → その高さに置かれる。同じ小節に4つで小節が埋まる
- [ ] 5つ目を置こうとすると入らず、理由の通知が出る（無言で失敗しない）
- [ ] 8分・16分・2分・全音符を置く。小節の幅が音符の数に応じて広がる
- [ ] 加線の上（五線の上/下）に置ける。ホバーのゴースト（薄い音符）が置く高さを示す
- [ ] 小節の途中の拍をクリックすると、手前が休符で埋まる（拍位置どおり）
- [ ] 左手（ヘ音記号）にも同様に置ける。レイヤーの「左手・声部1」に切り替わっている
- [ ] 数字キーで音価が切り替わる（例: 4 → 4分、8 → 8分）／`.` で付点

## 2. 選ぶ・消す・動かす
- [ ] 音符をクリックで選択（青）。← → で隣の音符へ移動、段の端で止まる
- [ ] ↑ ↓ で音高が1段ずつ動く。♯/♭ の調号に沿った音になる
- [ ] Delete で消える。何を消したか通知が出て、選択が解ける
- [ ] 消したあと Undo で戻る（1回で戻る）
- [ ] 音符をドラッグして上下に動かせる／小節の外へは出ない
- [ ] 小節選択ツール: 小節をクリック → 小節が選ばれる。Shift+クリックで範囲
- [ ] 選んだ小節で「小節を挿入」「小節を削除」（単一小節選択のとき出る）
- [ ] 移調パネル: 選択範囲を半音上・全音下・8va 上げる。Undo で戻る

## 3. 和音・声部
- [ ] 音符の上下（符頭の X 範囲）をクリックで和音に音が足される。同じ音は重複しない
- [ ] 和音の1音だけ選んで Delete → その音だけ消える
- [ ] レイヤーを「右手・声部2」にして音符を置く → 符幹が下向きの2声部になる
- [ ] 声部2の音符を全部消す → 単声部の表示に戻る
- [ ] 和音のとき「右手の左側にはみ出す音」（隣接音）の見た目が崩れない

## 4. 連符・付点・タイ
- [ ] 3連符ボタンで8分を3つ置く → 数字「3」付きで1拍に収まる
- [ ] ▾ から 5連符・6連符を選ぶ。ボタンに選んだ種類が残る
- [ ] 連符の途中の音を消す → 休符化してグループは保たれる
- [ ] 連符数字の表示切替で数字が消える/戻る
- [ ] 付点4分＋8分で1拍にぴったり収まる
- [ ] タイ: 同じ高さの隣り合う音符をドラッグで結ぶ。違う高さには結べない
- [ ] 段をまたぐタイ（段末→次段頭）が描ける

## 5. 臨時記号（今日変えたところ）
- [ ] ♯ / ♭ / ♮ にカーソルを置いた**瞬間**に吹き出しが出る。文言に「クリックした音だけ」が入っている
- [ ] ♯ を ON にして既存の音符をクリック → その音だけに ♯ が付く（音符は増えない）
- [ ] ♯ ON のまま空いた場所をクリック → ♯付きの新しい音符が入る
- [ ] ▾ から 𝄪（ダブルシャープ）を選ぶ → ボタンの記号が変わり、付与できる。¼♯ も同様
- [ ] 音価を変えても ♯ の選択は外れない（8分に変えてから置いても ♯ が乗る）
- [ ] 和音の1音だけに ♭ を付ける（他の音に付かない）
- [ ] 途中調号変更（演奏記号タブ）: ホバーで「クリックした小節から先」と出る。小節をクリック → 調号を選ぶ → そこから先だけ変わる

## 6. 休符・小節・反復
- [ ] 休符ツールで4分休符を置く。全休符の小節に音符を置くと休符が消える
- [ ] リピート開始/終了を付ける。1番/2番括弧を付ける
- [ ] 段あたり小節数を 3 にして段割りが変わる／「段割りをリセット」で戻る
- [ ] 空の小節を末尾に「＋ 小節を追加」で増やす。内容が無い末尾は印刷プレビューに出ない

## 7. 演奏記号タブ
- [ ] 強弱: pp を音符に付ける。低い音符の下でも五線に重ならず、左手の五線に入らない
- [ ] cresc. / dim. を付ける。同じ位置に pp と cresc. を付けると行が分かれる
- [ ] 松葉 ＜: 開始音符から終了音符へドラッグ。＞ も同様
- [ ] スタッカート・アクセント・テヌート・フェルマータを付ける／もう一度で外れる
- [ ] 前打音・トリル・モルデント・ターンを付ける
- [ ] 歌詞・コード記号・テンポ表記・発想標語・運指を1つずつ入れる（テキスト入力の欄が出る）
- [ ] Ped と ✱ を左手の音符に付ける → 破線でつながる。**低い和音（加線の下）の Ped が重ならない**（今日の修正）
- [ ] 8va を右手に付けて終点も付ける → 破線ブラケット。高い音があるとブラケットが避ける
- [ ] ⤢（サイズ）✥（位置）で pp を動かす。ドラッグ中に値が出る。Undo で戻る
- [ ] 記号をそのまま掴んでドラッグでも動く（選択なしで）
- [ ] カスタム記号: ＋ で描いて保存 → パレットに増える → 付与できる。手ぶれ補正のON/OFF
- [ ] 途中テンポ変更・途中拍子変更・途中音部記号変更（小節をクリックして指定）

## 8. 段またぎ（ピアノ譜）
- [ ] 右手の音符を選んで「段またぎ表示」→ 左手の五線に描かれ、符幹・連桁が向きを変える
- [ ] 段またぎした音符の当たり判定が左手側にある（クリックで選べる）
- [ ] 段またぎに Ped を付ける → 左手の五線の下に出る
- [ ] 解除で右手に戻る

## 9. レイアウトタブ（整えるモード）
- [ ] タブを開くと2段目以降の上端に薄い帯、段の左右端が色づく。音符・休符タブに戻すと消える
- [ ] 帯をドラッグ → その段の間隔が変わる。掴んだだけで離すと Undo に何も積まれない
- [ ] 段の右下 ◢ を斜めにドラッグ → 全体の音符の大きさが変わる。吹き出しに「（全体）: N%」
- [ ] 帯を掴んでいる間に ◢ は掴めない（同時に2つ動かない）
- [ ] スライダー: 音符の大きさ 150% / 段の間隔 / パート間隔 / 均等さ。Undo 1回で戻る
- [ ] 用紙 A4 → B4 で段数/ページの推奨値が変わる。余白スライダーで譜面領域が変わる
- [ ] 印刷プレビュー: 段が用紙に収まる。Ped が段の下端で切れない
- [ ] リセット ▾: レイアウトのリセット／プリセット保存→削除

## 10. 保存・切替・出入力
- [ ] 編集して数秒待つ → ホームの「最近使ったファイル」の更新時刻が変わる（自動保存）
- [ ] 作品一覧で別の作品へ切り替え → 戻ると編集内容が残っている
- [ ] 履歴（作品一覧の「履歴」）から1つ前に戻せる
- [ ] 書き出し: .score.json / MusicXML / PDF。MusicXML を「開く」で読み直して同じ見た目
- [ ] 月光（.score.json）を開き直して表示が崩れない（段割り [3,3,3]・Ped の位置）

## 11. 再生 🔇（マイク OFF のときだけ）
- [ ] 白紙で作った譜面を再生 → 置いた音が順に鳴る。ハイライトが音符に追従
- [ ] 作品を切り替えた**直後**に再生 → 切り替え先が鳴る（今日の修正）。切り替え直後の一瞬は再生ボタンが押せない
- [ ] 再生中に別の作品へ切り替え → 音が止まる
- [ ] 一時停止→別の作品→再生 → 新しい作品が最初から
- [ ] 小節番号を指定して再生 / 途中で停止 → もう一度再生で頭から
- [ ] pp を付けた音が小さく鳴る（右手に付けても左手も小さくなる）
- [ ] 月光（ペダル版）を通しで聴いて途切れ・欠けが無い
