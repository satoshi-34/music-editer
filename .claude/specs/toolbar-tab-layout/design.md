# ツールバーのタブ化

## 背景

強弱記号、拍子、終止括弧、再生設定などの追加で
固定ツールバーの横幅が足りなくなり、

- サンプルボタンが切れる
- ヘッダーが高くなったとき本文と重なる
- 関係ない操作群が常に並んで視認性が落ちる

という問題が出た。

## 方針

### 1. 操作群を4つのタブへ分ける

- `音符・記号`
- `楽譜設定`
- `再生・音色`
- `その他`

各タブでは、その場で必要な操作だけを見せる。

### 2. 既存コンポーネントはなるべく再利用する

レイアウトだけを `ScorePage` 側で組み替え、

- `Palette`
- `PlaybackControls`
- `SaveLoadButtons`

の責務は大きく変えない。

これで既存の音声ロジックやツール状態の退行を減らす。

### 3. 固定ヘッダー高さは実測する

タブごとに中身の高さが違うため、
CSS の固定値だけでは本文が潜り込みやすい。

そこで `ResizeObserver` でツールバー高さを測り、
`--toolbar-h` を React 側から更新する。

### 4. パネルは横スクロールを許す

パレットや再生詳細は最小でも一定幅が必要なので、
無理に縮めず `toolbar-panel` へ `overflow-x: auto` を付ける。

これで極端に狭い画面でも UI が壊れにくい。

## 変更対象

- `src/components/ScorePage.tsx`
- `src/App.css`
- `README.md`

## 注意点

- タブで隠れているだけで、各 state は保持したままにする
- `Y補正` のポップアップは `その他` タブ内へ残す
- 印刷時は従来どおりツールバー非表示を維持する
