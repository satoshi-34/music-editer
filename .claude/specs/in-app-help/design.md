# アプリ内ヘルプ（Issue #341）

2026-08-22。弟インタビュー回答1（#89）:「あらゆる操作の説明書が欲しい。調べるソースが脆弱だと厳しい」。

## 問題

操作の説明は README にしか無く、アプリを使いながら「やりたいこと」から手順を引けない。

## 修正設計（Issue の Codex レビュー済み方針 = 2層 + ソース一本化）

- **第1層: 目的別ガイド**（タスク起点）: `src/utils/helpContent.ts` の `TASK_GUIDES` が正本。
  「〜したい」形の見出し + 手順 + 検索用キーワード + リファレンスへの参照（seeAlso）
- **第2層: 操作リファレンス**（UI起点）: **README の操作章が唯一の正本**。
  `README.md?raw` を実行時に `parseReadmeSections` でパースして表示する（二重管理しない）。
  対象章はタイトルの内容語（画面/基本操作/応用操作/ショートカット/既知の制限）で選ぶため、
  章番号の振り直しに耐える。開発者向け章は載せない
- **検索**: 1つの検索ボックスで両層を横断。スペース区切りは AND、全角スペース・大文字小文字を正規化
- **UI**: ヘッダータブ行右端（フィードバックの左）に「❓ ヘルプ」を常設 → モーダル
  （HelpPanel）。ガイドは details で開閉、リファレンスは章見出しの下に項目を並べ、
  検索中は自動で開く。ガイドの「詳しく」で該当リファレンス項目へスクロール
- **markdown 描画**: 依存を増やさず簡易レンダラー（見出し/箇条書き/番号リスト/表/強調/コード。
  リンクは表示テキストへ落とす）

## データ構造

- `HelpSection { id, chapter, title, body }`（README パース結果・実行時のみ）
- `TaskGuide { id, title, keywords, steps, seeAlso? }`（コードが正本）
- 保存データへの影響なし

## 影響範囲

- 新規: utils/helpContent.ts・components/HelpPanel.tsx・App.css のヘルプ用スタイル
- ScorePage: ❓ ヘルプボタンと showHelp state のみ
- テスト: helpContent（パース・横断検索・**seeAlso が実物 README に実在すること**）7件、
  HelpPanel（2層表示・絞り込み・見つからない案内・閉じる・詳しくジャンプ）5件

## 経緯・既知の制限

- 「各ツールチップから該当項目へのリンク」（Issue 記載）は、ツールチップが title 属性
  （リンク不可）のため第1弾では見送り。ヘルプ検索で同じ語を引けることで代替
- ガイドの手順は README の記述と突き合わせて書いた。UI 文言を変えたら
  helpContent.test.ts の「seeAlso 実在」テストが README との乖離を検出する
