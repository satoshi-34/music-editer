# 設計書: エリーゼのために サンプル譜面寄せ

## 追記: 汎用ピアノデモフレーズへの差し替え

- その後の運用で、「有名曲らしさ」を追うより
  **このエディタで編集・再生・記号確認がしやすいこと** を優先したほうが
  サンプル用途に合うと判断した
- そのため `src/data/demoScores.ts` のピアノサンプルは、
  `fur-elise` という ID 互換は保ちつつ、
  実データと表示名を汎用の `Piano Demo / 3/8 Sample Phrase` へ差し替えた
- 新しいデモでは、`3/8`、8分休符、16分休符、左右手、リピート、
  1番括弧 / 2番括弧、強弱、和音を短い範囲で確認しやすいことを優先している

## 概要

既存の `エリーゼのために` サンプルは、
「3/8 の主題らしさを触れる説明用デモ」としては十分だった一方で、
有名な冒頭譜を見慣れたユーザーが期待する
**右手の内声、左手の分散和音、反復記号の見え方** までは十分に再現できていなかった。

そこで今回は、既存の描画・再生機能を活かしながら、
サンプル譜面を「有名なエリーゼ冒頭として認識しやすい形」へ寄せる。

## 問題点

- `src/data/demoScores.ts` の `createFurEliseDemoScore()` が簡略化されており、
  原譜の冒頭らしい見た目との差が大きい
- 右手は主旋律だけに近く、**同小節内の補助声部** を活かせていない
- 左手は和声の雰囲気確認には使えるが、
  有名な分散和音パターンとしては情報量が足りない
- README でも「主題デモ」であることは説明しているが、
  今回どこまで原譜寄せしたのかが伝わりにくい

## 修正方針

### 1. サンプル譜面データを原譜寄せで組み直す

- 対象は `createFurEliseDemoScore()`
- `3/8`、`C`（調号なし）を維持する
- 冒頭主題の見た目が分かる範囲で、
  右手・左手ともに音型を整理する
- 既存の 48 小節ぶんの器は維持し、先頭側の密度を高める

### 2. 冒頭は単声部寄りで整理する

- 比較画像から、冒頭主題は「情報を増やす」より
  **余白と休符を残す** ほうが近いと分かった
- そのため opening では `voices` を無理に使わず、
  まずは右手主旋律 + 左手の軽い分散和音へ戻す
- `voices` 基盤自体は残しつつ、今回の冒頭サンプルでは
  使いどころを絞る
- 手本で多用される右手の `8分音符 + 8分休符 + 16分音符2つ` と、
  左手の `16分音符3つ + 16分休符 + 8分休符` を優先して小節内の拍を合わせる
- 編集時は、音符ツールで休符をクリックしたときに
  1回目のクリックでは休符を選択し、
  同じ休符をもう一度クリックしたときに同音価ならそのまま音符へ置換し、
  短い音価なら休符を分割して差し込めるようにする。
  例: 16分音符ツールで16分休符をクリックすると16分音符へ置換、
  8分休符の右半分をクリックすると `16分休符 + 16分音符` へ置き換わる
- 選択した休符は Delete で削除でき、
  ↑/↓ で見た目の高さも調整できるようにする
- 再生時は各小節に拍子由来の `measureBeats` を渡し、
  空小節や入力途中の小節でも左右手が同じ小節長で進むようにする
- 多段譜のリピート記号と終止括弧は最上段の展開順を基準にし、
  片手だけに印が残っていても全段の再生順が分かれないようにする
- 現在のピアノ譜をローカルのカスタムサンプルとして保存できるようにし、
  手入力で詰めた譜面をそのままサンプル読込導線へ載せられるようにする
- 拍子記号はいまの仕様では譜面全体のいちばん最初だけに表示し、
  途中で拍子が変わる場所での再表示は別機能として実装する
- 音符を新規配置したときは確認音を鳴らし、
  休符を音符へ置換・分割したときも新しく入った音を確認できるようにする

### 3. 既存の記号確認用途は保つ

- リピート、1番括弧 / 2番括弧、強弱記号は引き続きサンプルに残す
- ただし「機能確認のために不自然な位置へ置く」のではなく、
  できるだけ音楽的に不自然でない場所へ寄せる

### 4. ドキュメント更新

- README のサンプル説明を更新し、
  「主題デモ」から「冒頭寄せサンプル」へ表現を改める
- どの機能をこのサンプルで確認できるかも整理する

### 5. 比較で見えた未実装項目を記録する

比較画像の完全一致には、サンプルデータ修正だけでなく
次の機能追加が必要である。

- テンポ指示テキスト（例: `Poco moto.`）
- ペダル記号テキスト（例: `Ped.`）
- 小節番号表示
- 音符にひもづかない独立テキスト記号
- 行頭の強弱を「最初の音符位置とは別」に置く機能

## セキュリティ・安定性配慮

- 外部データ取得は行わず、ローカルの固定サンプルだけを更新する
- `voices` 基盤は残しつつ、今回はデータを単純化して
  既存の保存・読込・再生との互換を壊さない
- 休符分割は「選択中の音価が元の休符より短く、残りも単一の音価で表せる場合」だけ行い、
  表せない分割では従来どおりの挿入処理へ戻す
- 未使用小節は引き続き空小節で埋め、
  ページ数や既存 UI レイアウトを急に変えない
