# 同時発音数の上限と再生後の後始末 — Issue #605

運用者QA（2026-09-03・全曲月光 69小節・ペダル全小節）「再生がプツプツ途切れる」と、
その先の「繰り返し再生したタブが部分的に無音化し、音声復旧でも直らない」への対処。
セッション内実装。

## 問題

1. **途切れ**: ペダル延長（#549/#560）で各音の鳴り終わりが解除位置まで延び、全曲では
   保持中のボイスが数十〜百単位に積み上がる。両エンジンとも同時発音の上限管理が無かった
2. **無音化**: sample-player（SoundFont の再生部品）は鳴り終わったノードの参照を
   `tracked` に持ち続け、`stop()` 以外で捨てる手段が無い。停止ボタンは stopAll で世代交代
   （player キャッシュ破棄）するが、**最後まで鳴り切った自然終了では stopAll を呼んでいなかった**
   ため、全曲を繰り返し聴くほどノード（Gain・ADSR・BufferSource）が積み上がる

## 設計

- `src/audio/polyphonyLimit.ts`: **純粋関数 `limitPolyphony(voices, max)`**。開始時刻順に
  走査し、鳴っている最中のボイスが上限に達したら**最も古く鳴り始めたもの**の終了時刻を
  新しい音の開始時刻まで詰める。同時刻に上限を超える和音は入力順の早い側が長さ 0（無音化）。
  計測用に `peakBefore / stolen / dropped` を返す
- 両エンジンとも譜面全体を予約時点で組み立てるので、上限は**予約前の静的計算**で掛ける:
  - `SoundFontEngine.playParts`: 予約をいったん一覧に集め、詰めてから `player.play`
  - `SimpleAudioEngine.playScore`: 受け皿（collector）を受け取ると積むだけにし、
    `playParts` が全パートぶん詰めてから `playNoteAtTime`。単独呼び出しは自前で詰める
  - 右手→左手の順に組み立てるため「鳴らしながら数える」では同時発音が分からない。
    一覧にしてから詰めるのはそのため
- 上限判定の区間は**余韻（release/尻尾）込み**＝ノードが実際に生きている期間（round1 P1）。
  詰めた音は、詰められた占有期間に「音本体 → 余韻」の順で収める: 音本体 = min(元の音価, 占有)、
  余韻 = 残り（round2 P1: 余韻の全量を先に引くと、余韻だけ切れば足りる短音まで無音化する）。
  占有 0 以下の音だけ予約しない。両エンジンとも余韻の長さを上書きできる引数を足した
- 計測用の `peakBefore` は詰める前の区間で独立に数える（`peakConcurrency`。round1 P2）
- `MAX_POLYPHONY = 48`（両エンジン共通・dev では #596 の `audio.maxPolyphony` で上書き）。
  値は運用者の耳で決める。両エンジンとも予約時に
  `ボイス N / 最大同時 P / 詰め S（うち無音化 D）/ 上限 M` をコンソールへ出す（仕様1の計測）
- **自然終了の後始末**（ScorePage `finishPlaybackNaturally`、通常・再開・代表音の全経路共通）:
  stopped にした後、余韻（`MAX_RELEASE_TAIL_SECONDS` + 0.5 秒）を待ってから**予約時のエンジン**で
  `stopAll()`（発火時の getAudioEngine() だと、余韻待ち中に音源方式を切り替えたとき新エンジンの
  プレビューを止める。round1 P2）。停止ボタンと同じ経路なので次の再生の音源先読みも走る。
  次の再生が先に来たら後始末は**取り消さずにその場で実行**（`flushPendingPlaybackCleanup`。
  取り消すだけだと 1.1 秒以内の繰り返し再生で旧世代が捨てられない。round1 P1）。
  停止ボタンは自前で stopAll するので予約だけ消す。**音色プレビュー・入力確認音の入口でも
  同じく即時実行**（round2 P2: 残したままだと発音途中で stopAll が走り、読み込み中なら
  SoundFontLoadAbortedError が「停止された」扱いで握りつぶされて無言に失敗する）
- 音声復旧の案内に「それでも鳴らない場合はタブを閉じて開き直す」を追加（下限ライン・#318）

## テスト

- `polyphonyLimit.test.ts`: 上限内は無変更・上限+1で最古が詰まる・鳴り終わりは数えない・
  同時刻の和音は無音化・入力順が時刻順でなくても正しい・既定値と dev 上書き
- `SoundFontEngine.test.ts`: 6音和音が上限4で4回予約・ペダル延長の古い音が新しい音の開始で止まる
- `pedalPlaybackEngines.test.ts`: 内蔵側で上限2なら2音ぶんのオシレーターしか作られない
- `ScorePagePlaybackEndCleanup.test.tsx`: 自然終了→余韻後に stopAll が1回、余韻待ち中の再生開始で即時実行（重複なし）、一時停止→再開→自然終了でも後始末

## やらなかったこと

- 実行時のボイススティール（鳴っている最中に動的に奪う）。予約時に全部分かるので不要
- sample-player の `tracked` を直接掃除すること（クロージャ内で触れない）。世代交代で代替
