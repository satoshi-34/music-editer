# 日本語使用ガイドライン

## 概要

このプロジェクトでは、すべてのチャットコミュニケーションとソースコード内のコメントを日本語で記述します。

## ルール

### チャットコミュニケーション
- ユーザーとのすべての会話は日本語で行う
- 技術的な説明も日本語で提供する
- エラーメッセージの説明も日本語で行う

### ソースコードのコメント
- すべてのコメントは日本語で記述する
- 関数やクラスの説明コメントは日本語で書く
- インラインコメントも日本語で記述する
- TODOコメントも日本語で記述する

### コミットメッセージ
**ハイブリッド形式**（1行目は英語、詳細は日本語）を使用する。

- **1行目（要約）**: 英語で記述する（Conventional Commits 形式）
- **2行目以降（詳細）**: 日本語の箇条書きで、具体的な修正内容・理由・背景を記述する
- 詳細が自明な場合は1行目のみでも可

#### 例
```
fix: solve coordinate mismatch on scaled canvas

- スケール適用時のクリック座標計算ロジックを修正
- getScreenCTM の逆行列を使用し、ズーム倍率に関わらず正確な位置を特定できるようにした
- 浮動小数点の丸め誤差を修正し、音符が線の上に正確にスナップするように改善
```

```
feat: add semitone transposition via Alt+arrow keys

- Alt+↑/↓ で半音移動する機能を追加
- 上移動はシャープ表記、下移動はフラット表記を採用
- keyToMidi / midiToKey を使って MIDI 番号経由で変換
```

### 例外
- 変数名、関数名、クラス名などの識別子は英語を使用（プログラミングの標準慣行に従う）
- ライブラリやフレームワークのAPIは英語のまま使用

## コメントの例

```typescript
// 良い例
/**
 * 譜面データをlocalStorageに保存する
 * @param data 保存する譜面データ
 * @returns 保存が成功した場合はtrue
 */
function saveScore(data: ScoreData): boolean {
  // localStorageの容量をチェック
  if (!hasEnoughSpace()) {
    // エラーをログに記録
    console.error('ストレージ容量が不足しています');
    return false;
  }
  
  // データをJSON形式にシリアライズ
  const json = JSON.stringify(data);
  
  // localStorageに保存
  localStorage.setItem(STORAGE_KEY, json);
  return true;
}
```

## 適用範囲

このガイドラインは以下のファイルに適用されます：
- すべての `.ts` ファイル
- すべての `.tsx` ファイル
- すべての `.js` ファイル
- すべての `.jsx` ファイル
- テストファイル（`.test.ts`, `.test.tsx`）
- ドキュメントファイル（`.md`）

## 注意事項

- 既存のコードを修正する際は、コメントを日本語に更新する
- 新しいコードを追加する際は、必ず日本語でコメントを記述する
- コードレビュー時は、コメントが日本語で記述されているか確認する
