# 日本語使用ガイドライン

## 概要

このプロジェクトでは、すべてのチャットコミュニケーションとソースコード内のコメントを日本語で記述します。

## ルール

### チャットコミュニケーション
- ユーザーとのすべての会話は日本語で行う
- 技術的な説明も日本語で提供する
- エラーメッセージの説明も日本語で行う

### ソースコードのコメント
- すべてのコメントは日本語で記述する
- 関数やクラスの説明コメントは日本語で書く
- インラインコメントも日本語で記述する
- TODOコメントも日本語で記述する

### 例外
- 変数名、関数名、クラス名などの識別子は英語を使用（プログラミングの標準慣行に従う）
- ライブラリやフレームワークのAPIは英語のまま使用
- コミットメッセージは英語でも日本語でも可

## コメントの例

```typescript
// 良い例
/**
 * 譜面データをlocalStorageに保存する
 * @param data 保存する譜面データ
 * @returns 保存が成功した場合はtrue
 */
function saveScore(data: ScoreData): boolean {
  // localStorageの容量をチェック
  if (!hasEnoughSpace()) {
    // エラーをログに記録
    console.error('ストレージ容量が不足しています');
    return false;
  }
  
  // データをJSON形式にシリアライズ
  const json = JSON.stringify(data);
  
  // localStorageに保存
  localStorage.setItem(STORAGE_KEY, json);
  return true;
}
```

## 適用範囲

このガイドラインは以下のファイルに適用されます：
- すべての `.ts` ファイル
- すべての `.tsx` ファイル
- すべての `.js` ファイル
- すべての `.jsx` ファイル
- テストファイル（`.test.ts`, `.test.tsx`）
- ドキュメントファイル（`.md`）

## 注意事項

- 既存のコードを修正する際は、コメントを日本語に更新する
- 新しいコードを追加する際は、必ず日本語でコメントを記述する
- コードレビュー時は、コメントが日本語で記述されているか確認する
