# 設計書: 譜面ページ高さの統一

## 問題

`ScaledPageWrapper` が各ページを個別に実測していたため、タイトル・サブタイトル・作者欄を持つ1ページ目だけ内容高さが増えると、ページ本体とグリッド上の占有高さがページごとに分かれていた。

## 修正設計

- `ScorePage` で表示中の `.print-page` をまとめて計測する
- 最大の内容高さを同じ譜面の全ページへ渡す
- `.page-head` にタイトル欄ぶんの最小高さを持たせ、五線の開始位置も全ページでそろえる
- `ScaledPageWrapper` は共有高さを `height` と `--page-height` として適用する
- `.print-page` は `--page-height` を `min-height` に使い、紙面の白背景も外側ラッパーも同じ高さにする
- 内容がA4を超える場合は、A4へ切り詰めず、最大ページの高さを維持する

## 影響範囲

- `src/components/ScorePage.tsx`: 表示中ページの最大高さを計測して共有
- `src/components/ScaledPageWrapper.tsx`: 共有高さの受け取りと紙面・ラッパーへの反映
- `src/App.css`: 共通高さを紙面の最小高さへ反映
- `src/App.css`: ページヘッダーの共通高さを設定
- `README.md`: ページ高さ統一の機能と実装ポイントを追記

## 最小チェック

- タイトル欄のある1ページ目と2ページ目以降の紙面下端がそろっている
- `npm run build` が成功する
- ブラウザのコンソールにエラーがない
