# ツールバーのタブ化

`.claude/specs/toolbar-tab-layout/design.md` と同じ意図で、
増え続ける操作ボタンを 1 行へ押し込まず、
タブ切り替えでコンパクトに見せる。

## 目的

- サンプルボタンや補助ボタンが見切れないようにする
- 音符入力中に再生設定が常時邪魔しないようにする
- 固定ヘッダーでも本文と重ならないようにする

## 構成

- `音符・記号`: `Palette`
- `楽譜設定`: 楽譜種類 / 拍子 / 調号
- `再生・音色`: `PlaybackControls`
- `その他`: 保存 / 読込 / サンプル / 印刷 / Y補正

## 実装メモ

- ヘッダー高さは `ResizeObserver` で実測して `--toolbar-h` へ反映
- `toolbar-panel` は横スクロール可にして、最小幅を守る
- 個々の既存コンポーネントは大改造せず、`ScorePage` で並べ替える
