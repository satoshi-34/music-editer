# 拍子記号と1番括弧/2番括弧の実装

`.claude/specs/time-signature-and-ending-implementation/design.md` と同じ方針で、
譜面の構造を `4/4 固定` から外し、
終止括弧の基本分岐まで扱えるようにする。

## 目的

- 譜面ごとに `3/8` などの拍子を持てるようにする
- 表示だけでなく、入力制限と再生時間計算も拍子へそろえる
- `1番括弧 / 2番括弧` を表示し、再生展開でも分岐させる

## 保存形式

- `SavedScoreData.timeSignature?: [number, number]`
- `MeasureData.ending?: 1 | 2`

旧データ互換:

- `timeSignature` が無ければ `4/4`
- `ending` が無ければ終止括弧なし

## 実装メモ

### 拍子

- `timeSignatureUtils.ts` で検証、正規化、拍数計算、表示文字列生成を共通化
- `StaffCanvas` / `PianoSystemCanvas` の `BEATS_PER_MEASURE = 4` 依存を置き換える
- `ScorePage` では UI から拍子を選べるようにし、保存 / 読込 / サンプル読込へ反映する

### 終止括弧

- パレットへ `1.` / `2.` ツールを追加
- クリックした小節へ `ending` 番号を付ける
- 描画時は `ending` の連続範囲から `BEGIN / MID / END / BEGIN_END` を決める
- 再生時は 1周目なら `ending: 1`、2周目なら `ending: 2` だけ鳴らす

## 注意点

- `エリーゼのために` デモ譜は `3/8` の主題デモへ更新し、
  16分音符主体の冒頭リズムも持たせたが、
  原典版全体の構成や細かな装飾はまだ省略している
- 一方で、リピート記号・1番括弧 / 2番括弧・強弱記号はサンプルへ実際に入れ、
  機能確認用としてすぐ触れる状態にしている
- 1番括弧 / 2番括弧はまず単純な反復を安全に扱う範囲で導入している
