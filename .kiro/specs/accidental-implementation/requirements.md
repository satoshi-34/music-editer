# 要件: 臨時記号実装

## 要件一覧

### 要件1: シャープ・フラット表示
- `keys` に `#` または `b` を含む音は、同小節内で必要な最初の位置に臨時記号を表示できること

### 要件1.1: UI からの選択
- ユーザーはパレットの `♯ / ♭ / ♮` ボタンを選択して、対象音符へ臨時記号を適用できること

### 要件2: ナチュラル表示
- 同じ小節内で直前まで変化していた同音名・同オクターブの音を自然音へ戻した場合、`n` を表示できること

### 要件3: 重複表示抑制
- 同じ小節内で同じ臨時記号状態が継続する場合、不要な重複表示をしないこと

### 要件4: 譜面種別一貫性
- 単旋律譜・ピアノ譜・弦楽四重奏譜のすべてで同じ臨時記号ルールが適用されること

### 要件5: 保存データ安全性
- 不正な音高キー文字列を含むデータは保存時に拒否されること
