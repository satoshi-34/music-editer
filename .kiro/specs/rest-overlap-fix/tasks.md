# 実装計画: 休符重なり修正（シンプル化）

## 概要

Vexflowの`setCenterAlignment`を無効化し、時間ベースの位置計算により休符の重なり問題を解決する。最小限の変更で最大の効果を得るシンプルなアプローチ。

  - 休符作成時の`setCenterAlignment(true)`を削除
  - 中央揃えを無効化して標準の位置計算を使用
  - 既存の音符処理は変更なし
  - _要件: 1.1, 1.2_

- [x] 1.1 makeVFNote修正の単体テストを作成
