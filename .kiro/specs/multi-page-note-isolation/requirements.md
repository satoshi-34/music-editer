# 要件定義書

## はじめに

五線譜エディタにおいて、1ページ目で音符を追加すると、2ページ目の同じ相対位置にも音符が追加されてしまう不具合を修正します。この問題は、複数ページのレイアウトにおいて、クリックイベントハンドラーが正しい小節インデックスを参照していないことに起因すると考えられます。

## 用語集

- **StaffCanvas**: 五線譜を描画し、音符の配置を管理するReactコンポーネント
- **小節（Measure）**: 楽譜の基本単位。4拍で構成される
- **小節インデックス（measureIndex）**: 楽譜全体における小節の位置を示す番号（0から始まる）
- **ページ（Page/System）**: 複数の小節を含む1行の五線譜
- **globalIndex**: ループ内で使用される、現在描画中の小節の絶対位置
- **クロージャ**: 関数が定義されたスコープの変数を参照し続ける仕組み

## 要件

### 要件 1: 小節インデックスの正確な参照

**ユーザーストーリー:** エディタ利用者として、特定のページの特定の小節をクリックした際、その小節にのみ音符が追加されることを期待します。これにより、意図した小節にのみ音符を配置できます。

#### 受入基準

1. WHEN ユーザーが1ページ目の小節をクリックした場合、THE システムは1ページ目の該当小節にのみ音符を追加しなければならない
2. WHEN ユーザーが2ページ目の小節をクリックした場合、THE システムは2ページ目の該当小節にのみ音符を追加しなければならない
3. WHEN クリックイベントハンドラーが小節インデックスを参照する場合、THE システムは正しいスコープの変数を使用しなければならない
4. WHEN 複数のイベントハンドラーが同じ小節インデックスを参照する場合、THE システムは各ハンドラーが独立した値を保持しなければならない

### 要件 2: イベントハンドラーのスコープ管理

**ユーザーストーリー:** 開発者として、イベントハンドラーが正しいスコープの変数を参照することを期待します。これにより、クロージャによる予期しない動作を防ぎます。

#### 受入基準

1. WHEN イベントハンドラーをループ内で定義する場合、THE システムは各反復で独立したスコープを作成しなければならない
2. WHEN 変数をクロージャでキャプチャする場合、THE システムは意図した値が保持されることを保証しなければならない
3. WHEN `measureIndex`変数を使用する場合、THE システムは各小節に対して正しい値を参照しなければならない
4. WHEN 複数のイベントリスナーが同じ変数を参照する場合、THE システムは各リスナーが独立した値を持つことを保証しなければならない

### 要件 3: 音符追加の分離

**ユーザーストーリー:** エディタ利用者として、音符を追加した際、他のページや他の小節に影響が出ないことを期待します。

#### 受入基準

1. WHEN ユーザーが特定の小節に音符を追加した場合、THE システムは他の小節のデータを変更してはならない
2. WHEN 音符追加処理を実行する場合、THE システムは対象の小節インデックスを正確に特定しなければならない
3. WHEN 複数ページにわたる楽譜を編集する場合、THE システムは各ページの小節を独立して管理しなければならない
4. WHEN 音符を追加する前に小節インデックスを検証する場合、THE システムは範囲外のインデックスを拒否しなければならない

### 要件 4: デバッグとロギング

**ユーザーストーリー:** 開発者として、音符追加時にどの小節が対象になっているかを確認できることを期待します。これにより、問題の診断が容易になります。

#### 受入基準

1. WHEN 音符追加処理が実行される場合、THE システムは対象の小節インデックスをコンソールに出力しなければならない
2. WHEN クリックイベントが発生した場合、THE システムはクリック位置と対象小節の情報をログに記録しなければならない
3. WHEN 予期しない小節インデックスが検出された場合、THE システムは警告メッセージを出力しなければならない
4. WHEN デバッグモードが有効な場合、THE システムは詳細なイベント情報を出力しなければならない

### 要件 5: 既存機能の保持

**ユーザーストーリー:** エディタ利用者として、修正後も既存の編集機能が正常に動作することを期待します。

#### 受入基準

1. WHEN 小節インデックスの参照を修正した場合、THE システムは音符の選択機能を維持しなければならない
2. WHEN 小節インデックスの参照を修正した場合、THE システムはガイドライン表示機能を維持しなければならない
3. WHEN 小節インデックスの参照を修正した場合、THE システムは音符の削除機能を維持しなければならない
4. WHEN 小節インデックスの参照を修正した場合、THE システムは複数ページのレイアウト機能を維持しなければならない
