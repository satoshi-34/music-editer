# 要件定義書

## はじめに

五線譜エディタにおいて、ユーザーがクリックした位置と実際に音符が描画される位置にずれが生じる不具合を修正します。この問題は、SVG座標変換の精度不足や、スケーリング適用時の座標計算の誤りに起因すると考えられます。

## 用語集

- **StaffCanvas**: 五線譜を描画し、音符の配置を管理するReactコンポーネント
- **SVG座標系**: SVGグラフィックスの内部座標系
- **クライアント座標系**: ブラウザのビューポート座標系
- **座標変換**: クライアント座標系からSVG座標系への変換処理
- **スケール**: 譜面の表示倍率（0.75〜1.0の範囲）
- **Vexflow**: 楽譜レンダリングライブラリ
- **ガイドライン**: クリック時に表示される横線と点のビジュアルフィードバック

## 要件

### 要件 1: 正確な座標変換

**ユーザーストーリー:** エディタ利用者として、クリックした位置に正確に音符が配置されることを期待します。これにより、直感的な譜面編集が可能になります。

#### 受入基準

1. WHEN ユーザーが五線譜上の任意の位置をクリックした場合、THE システムはクライアント座標をSVG座標に正確に変換しなければならない
2. WHEN スケール変換が適用されている場合、THE システムは変換行列を考慮した座標計算を行わなければならない
3. WHEN 座標変換を実行する場合、THE システムは`getScreenCTM()`メソッドを使用して正確な変換行列を取得しなければならない
4. WHEN 複数のSVGグループが存在する場合、THE システムは正しいルートグループに対して座標変換を実行しなければならない

### 要件 2: ガイドラインの位置精度

**ユーザーストーリー:** エディタ利用者として、マウスカーソルの位置に正確にガイドラインが表示されることを期待します。これにより、音符を配置する前に正確な位置を確認できます。

#### 受入基準

1. WHEN ユーザーが五線譜上でマウスを移動した場合、THE システムはガイドライン（横線と点）をカーソル位置に正確に表示しなければならない
2. WHEN ガイドラインを更新する場合、THE システムは変換後のSVG座標を使用しなければならない
3. WHEN ガイドラインの縦位置を決定する場合、THE システムは最も近い線または間にスナップしなければならない
4. WHEN ガイドラインの横位置を決定する場合、THE システムは小節の境界内に制限しなければならない

### 要件 3: 音符挿入位置の正確性

**ユーザーストーリー:** エディタ利用者として、クリックした位置に音符が正確に挿入されることを期待します。これにより、意図した通りの譜面を作成できます。

#### 受入基準

1. WHEN ユーザーが空の領域をクリックした場合、THE システムはクリック位置に基づいて適切な挿入位置を計算しなければならない
2. WHEN 挿入位置を計算する場合、THE システムは小節内の相対的な拍位置を考慮しなければならない
3. WHEN 音符の高さを決定する場合、THE システムはクリック位置のY座標から正確な音高を計算しなければならない
4. WHEN 既存の音符の近くをクリックした場合、THE システムは選択と挿入を適切に判別しなければならない

### 要件 4: スケール適用時の一貫性

**ユーザーストーリー:** エディタ利用者として、表示倍率が変更されても、クリック位置と音符配置の精度が維持されることを期待します。

#### 受入基準

1. WHEN スケール値が変更された場合、THE システムは座標変換にスケール値を正確に反映しなければならない
2. WHEN スケール適用後に座標を計算する場合、THE システムは一貫した変換方法を使用しなければならない
3. WHEN 異なるスケール値で描画された譜面をクリックした場合、THE システムは同じ相対位置に音符を配置しなければならない
4. WHEN スケールが0.75から1.0の範囲で変化する場合、THE システムは全ての範囲で正確な座標変換を維持しなければならない

### 要件 5: 既存機能の保持

**ユーザーストーリー:** エディタ利用者として、座標修正後も既存の編集機能が正常に動作することを期待します。

#### 受入基準

1. WHEN 座標変換を修正した場合、THE システムは音符の選択機能を維持しなければならない
2. WHEN 座標変換を修正した場合、THE システムはキーボードによる音符の移動機能を維持しなければならない
3. WHEN 座標変換を修正した場合、THE システムは音符の削除機能を維持しなければならない
4. WHEN 座標変換を修正した場合、THE システムは複数ページのレイアウト機能を維持しなければならない
