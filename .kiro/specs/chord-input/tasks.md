# 実装計画: 和音入力機能（chord-input）

## 概要

`NoteEvent` の `key: string` を `keys: string[]` に拡張し、和音の入力・表示・再生・保存を実現する。
既存のアーキテクチャ（VexFlow 描画、Tone.js 再生、localStorage 永続化）を活用しながら後方互換性を維持する。
